# Account Manager (Client Relationship Manager) Overview

O*NET describes service sales representatives as contacting customers, answering questions, developing proposals, explaining terms, and matching services to needs.

Use that context only as a role anchor. Inspect current local evidence, separate
verified facts from provided claims and assumptions, and state what remains unknown.
