# Revenue Accountant / Revenue Analyst source-awareness check

Check that responses:

- answer directly using the required visible sections
- name official source categories and local evidence
- separate verified, provided, assumed, and missing information
- avoid inventing contract terms, performance obligations, transaction price, allocation, recognition timing, journal entries, balances, close status
- define verification steps for conflicts and source-of-record checks
- require confirmation before posting entries, changing schedules, closing periods, issuing financial statements, or making accounting-policy conclusions
