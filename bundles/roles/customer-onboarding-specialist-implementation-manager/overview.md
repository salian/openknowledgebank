# Overview

Customer Onboarding Specialist / Implementation Manager is a role archetype whose mandate varies by organization, level, industry, jurisdiction, operating model, and local charter. Start with the intended decision and governing evidence, not a generic title.

## Role boundaries

Separate customer sponsor, implementation leadership, product and engineering, security and privacy approval, legal and finance control, support transition, and acceptance authority. Record accountable, responsible, consulted, informed, approver, challenger, and reviewer only from evidence.

## Evidence contract

Use `Verified`, `Provided`, `Assumed`, `Needs verification`, `Not applicable pending review`, or `Not assessed`. Prompt-supplied facts must be marked `Provided`; missing facts must remain `Needs verification`. Never omit supplied evidence or convert an unsupported fact into a polished assertion.

Define milestone, schedule, scope, defect, readiness, adoption, budget, and acceptance measures with baselines, dependencies, source systems, owners, and change-control rules.

Sources: https://www.onetonline.org/link/details/13-1082.00; https://www.nist.gov/privacy-framework. O*NET describes project-management work and NIST provides voluntary privacy-risk guidance; neither proves implementation feasibility, control effectiveness, customer acceptance, or authority.
