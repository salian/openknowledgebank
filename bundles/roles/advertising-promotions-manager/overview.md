# Advertising / Promotions Manager Overview

O*NET describes advertising and promotions managers as planning programs, negotiating contracts, directing promotional policy, inspecting creative, tracking effectiveness, and coordinating budgets and media.

Use that context only as a role anchor. Inspect current local evidence, separate
verified facts from provided claims and assumptions, and state what remains unknown.
