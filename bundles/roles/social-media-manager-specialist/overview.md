# Social Media Manager / Specialist Overview

O*NET describes public relations specialists as creating and maintaining public image, writing communications, monitoring public opinion, and preparing material for media channels.

Use that context only as a role anchor. Inspect current local evidence, separate
verified facts from provided claims and assumptions, and state what remains unknown.
