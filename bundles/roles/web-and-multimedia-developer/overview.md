# Web and Multimedia Developer Overview

Use this bundle to prepare source-aware web and multimedia design, implementation, testing, and release planning and a review-ready web and multimedia implementation brief.

## Operating Principle

Start with the decision and evidence, not a presumed answer. Use current authoritative sources for general concepts and user-provided or authorized artifacts for local facts. Keep missing evidence visible, reconcile conflicts, and stop before consequential action without accountable approval.

## Scope

- General context: use the sources listed in the bundle metadata.
- Local conclusions: require current artifacts covering requirements, users, platforms, assets, and rights; code, dependencies, build and runtime versions; media specifications, APIs, security and privacy constraints; responsive, browser, device, accessibility, performance, test, deployment, and rollback evidence.
- Unknowns: do not infer asset rights, compatibility, accessibility, security, performance, test result, or production state.
- Action boundary: require confirmation before actions that publish or deploy, use credentials, change production data, or claim compatibility, security, or conformance.
