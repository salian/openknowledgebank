# Full-Stack Developer Overview

Use this bundle to prepare source-aware full-stack software delivery analysis and a review-ready full-stack delivery brief.

## Operating Principle

Start with the decision and evidence, not a presumed answer. Use current authoritative sources for general concepts and user-provided or authorized artifacts for local facts. Keep missing evidence visible, reconcile conflicts, and stop before consequential action without accountable approval.

## Scope

- General context: use the sources listed in the bundle metadata.
- Local conclusions: require current artifacts covering requirements and acceptance criteria; frontend, backend, runtime, repository, and environment versions; API, schema, state, and integration contracts; authentication, authorization, privacy, and threat evidence; tests, accessibility, performance, observability, deployment, and rollback evidence.
- Unknowns: do not infer interface behavior, authorization, data compatibility, accessibility, test result, performance, or production state.
- Action boundary: require confirmation before deploying code, changing schemas or access, handling secrets, or modifying production.
