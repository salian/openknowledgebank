# Email Marketing Specialist / Manager Overview

O*NET describes marketing specialists as researching markets, measuring program effectiveness, collecting customer data, and developing marketing recommendations; email work is treated as a specialization requiring channel evidence.

Use that context only as a role anchor. Inspect current local evidence, separate
verified facts from provided claims and assumptions, and state what remains unknown.
