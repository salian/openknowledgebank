# Copywriter / Content Writer Overview

O*NET describes writers and authors as originating written material, adapting language and tone, researching factual detail, revising drafts, and submitting work for approval.

Use that occupational context only as a role anchor. For a real request, inspect
the local evidence, separate verified facts from supplied claims and assumptions,
and state what remains unknown.
