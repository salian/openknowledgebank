# Budget Analyst Overview

Use this bundle to prepare source-aware budget formulation, variance analysis, and funding recommendation and a review-ready budget analysis brief.

## Operating Principle

Start with the decision and evidence, not a presumed answer. Use current authoritative sources for general concepts and user-provided or authorized artifacts for local facts. Keep missing evidence visible, reconcile conflicts, and stop before consequential action without accountable approval.

## Scope

- General context: use the sources listed in the bundle metadata.
- Local conclusions: require current artifacts covering entity, program, period, appropriation, and funding authority; actuals, commitments, allocations, and source-system extracts; forecast assumptions and scenarios; variance definitions and calculations; request documentation and approvals.
- Unknowns: do not infer available funds, forecast outcome, variance cause, allowability, or spending authority.
- Action boundary: require confirmation before actions that change a budget, commit funds, approve a request, or make a public financial claim.
