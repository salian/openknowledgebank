# Platform / API Product Manager Overview

Use this bundle to prepare source-aware platform and API product management analysis and a review-ready platform API product brief.

## Operating Principle

Start with the decision and evidence, not a presumed answer. Use current authoritative sources for general concepts and user-provided or authorized artifacts for local facts. Keep missing evidence visible, reconcile conflicts, and stop before consequential action without accountable approval.

## Scope

- General context: use the sources listed in the bundle metadata.
- Local conclusions: require current artifacts covering product strategy, users, use cases, and decision criteria; API contract, schema, versions, compatibility, and lifecycle; authentication, scopes, privacy, abuse, and security model; reliability objectives, limits, dependencies, and support evidence; developer research, roadmap, economics, governance, and approval.
- Unknowns: do not infer developer need, API behavior, compatibility, reliability, security posture, roadmap commitment, or product outcome.
- Action boundary: require confirmation before changing contracts, deprecating versions, granting access, committing roadmap dates, or changing pricing.
