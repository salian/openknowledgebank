# Information Architect Overview

Use this bundle to prepare source-aware information architecture and findability analysis and a review-ready information architecture brief.

## Operating Principle

Start with the decision and evidence, not a presumed answer. Use current authoritative sources for general concepts and user-provided or authorized artifacts for local facts. Keep missing evidence visible, reconcile conflicts, and stop before consequential action without accountable approval.

## Scope

- General context: use the sources listed in the bundle metadata.
- Local conclusions: require current artifacts covering users, tasks, research, content inventory, and supported channels; current taxonomy, labels, navigation, search, metadata, and governance; analytics, search logs, card sorts, tree tests, and sampling limits; content ownership, lifecycle, permissions, localization, and accessibility; alternatives, prototypes, validation results, migration, and approval.
- Unknowns: do not infer user mental model, label comprehension, findability, taxonomy completeness, test outcome, content ownership, or implementation state.
- Action boundary: require confirmation before publishing navigation, migrating content, changing permissions or metadata, or claiming usability or accessibility.
