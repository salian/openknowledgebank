# Customer Support Engineer / Product Support Engineer Overview

O*NET describes computer user support specialists as diagnosing problems, guiding users, testing systems, documenting issues, and referring major problems to appropriate teams.

Use that context only as a role anchor. Inspect current local evidence, separate
verified facts from provided claims and assumptions, and state what remains unknown.
