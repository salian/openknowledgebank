# Marketing / Web Analytics Specialist Overview

Use this bundle to prepare source-aware marketing web analytics analysis and a review-ready web analytics measurement brief.

## Operating Principle

Start with the decision and evidence, not a presumed answer. Use current authoritative sources for general concepts and user-provided or authorized artifacts for local facts. Keep missing evidence visible, reconcile conflicts, and stop before consequential action without accountable approval.

## Scope

- General context: use the sources listed in the bundle metadata.
- Local conclusions: require current artifacts covering business question, property, streams, accounts, and access; tag-manager, analytics, consent, and platform versions; event and conversion definitions with implementation evidence; filters, identity, attribution, time zone, and reporting scope; data quality, reconciliation, privacy, retention, and review.
- Unknowns: do not infer tag deployment, consent state, event meaning, attribution, data completeness, conversion result, or user identity.
- Action boundary: require confirmation before deploying tags, changing consent behavior, exporting personal data, or publishing performance claims.
