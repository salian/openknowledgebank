# Growth Product Manager Overview

O*NET marketing-manager context supports customer, demand, strategy, and program-effectiveness work; the mapping is approximate and does not define product-management authority.

Use that context only as a role anchor. Inspect current local evidence, separate
verified facts from provided claims and assumptions, and state what remains unknown.
