# Data Analyst Overview

Use this bundle to prepare source-aware data analysis and decision support analysis and a review-ready data analysis brief.

## Operating Principle

Start with the decision and evidence, not a presumed answer. Use current authoritative sources for general concepts and user-provided or authorized artifacts for local facts. Keep missing evidence visible, reconcile conflicts, and stop before consequential action without accountable approval.

## Scope

- General context: use the sources listed in the bundle metadata.
- Local conclusions: require current artifacts covering decision question, stakeholders, population, period, and acceptance criteria; source systems, schema, grain, lineage, and ownership; data quality, exclusions, and missingness; metric definitions, transformations, filters, and reconciliations; statistical method and uncertainty; privacy, access, review, and publication context.
- Unknowns: do not infer data meaning, population completeness, metric definition, statistical significance, causality, or current result.
- Action boundary: require confirmation before querying sensitive data, publishing findings, changing production dashboards, or asserting causality.
