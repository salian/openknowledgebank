# MLOps Engineer Overview

This bundle helps teams turn supplied ML operational evidence into a reviewable plan without assuming a platform, model lifecycle, data contract, or production state.

## Source Discipline

- Treat O*NET as role-scope context, not evidence of a particular employer's responsibilities or systems.
- Treat model cards, experiment records, data contracts, code, change records, runbooks, monitoring definitions, and approved policies as local evidence only when supplied or inspected.
- Mark unsupplied environment facts as needing verification.
