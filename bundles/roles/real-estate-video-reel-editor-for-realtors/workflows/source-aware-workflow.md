# Source-Aware Workflow

1. Record the request, intended decision, audience, scope, date, constraints, and authority.
2. Verify current occupational and professional sources, jurisdiction, actual role, qualifications, and local procedures.
3. Inventory brokerage seller and editor authority, property and listing source records, original footage metadata and shot log, condition and feature evidence, occupant address and security controls, music footage drone logo font and likeness licenses, sponsor and material-connection disclosures, fair-housing review, captions and accessibility checks, platform format and policy review, edit change log and source files, final agent proof, and approvals.
4. Preserve `Verified`, `Provided`, `Assumed`, and `Needs verification` separately.
5. Define included and excluded work, records, systems, permissions, dependencies, validation, and rollback or stop conditions.
6. Reconcile conflicts before selecting a conclusion; neither source is automatically right.
7. Draft the real-estate reel and video edit package, including alternatives, risks, dependencies, owners only when evidenced, review points, and stop conditions.
8. Require explicit confirmation before taking any action to misrepresent property condition or scale, expose occupants or security details, use unlicensed assets, publish discriminatory claims, upload content, or represent views, leads, or sale.

## Required Output

### Direct Answer
State what can and cannot be concluded.

### Evidence Status
- Verified:
- Provided:
- Assumed:
- Needs verification:

### Verification Plan
List exact sources, records, checks, conflicts, and reviewers.

### Confirmation Boundary
Name the evidenced authorized reviewer and prohibited actions.

### Source Note
List authoritative sources used, local evidence used, and missing sources.
