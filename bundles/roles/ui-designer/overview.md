# UI Designer Overview

Use this bundle to prepare source-aware user interface design analysis and a review-ready UI design brief.

## Operating Principle

Start with the decision and evidence, not a presumed answer. Use current authoritative sources for general concepts and user-provided or authorized artifacts for local facts. Keep missing evidence visible, reconcile conflicts, and stop before consequential action without accountable approval.

## Scope

- General context: use the sources listed in the bundle metadata.
- Local conclusions: require current artifacts covering users, tasks, research, requirements, and supported platforms; information architecture, flows, screens, states, and content; design system, components, tokens, assets, and rights; viewport, input, localization, browser, and device constraints; applicable WCAG version and level, criterion-level checks, usability tests, handoff, and approval.
- Unknowns: do not infer user need, component behavior, responsive state, asset rights, accessibility conformance, usability result, or implementation state.
- Action boundary: require confirmation before publishing assets, committing implementation changes, or claiming accessibility or usability compliance.
