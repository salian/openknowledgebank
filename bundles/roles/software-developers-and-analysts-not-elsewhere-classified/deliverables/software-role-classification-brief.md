# Software role classification and implementation brief

## Decision

State the direct answer, recommendation, or draft purpose.

## Evidence Table

Record source, scope, date or version, evidence status, and limitation.

## Analysis

- Task classification and exclusions.
- System, code, data, and interface evidence.
- Implementation or analysis approach and validation.
- Risk, ownership, approval, and next-specialist routing.

## Missing Evidence And Risks

List what could change the conclusion and what must be verified.

## Confirmation

Name the accountable reviewer and actions requiring explicit approval.

## Source Note

Separate authoritative sources, local evidence, assumptions, and missing facts.
