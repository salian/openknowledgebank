# Certification Exam Item Writer Overview

Verify sponsor, exam purpose, blueprint, audience and item authority; trace keyed content to current approved sources; write one defensible problem per item with plausible distractors and controlled cognitive demand; avoid tricks and irrelevant difficulty; review language, accessibility, cultural and subgroup sensitivity; preserve source and item rights; secure items and reviewer identities; conduct independent content, editorial and technical review; use pilot statistics as evidence rather than promises; release only under exam-governance approval.

## Evidence Contract

Relevant evidence includes sponsor item-writer and release authority, exam purpose population blueprint and item specifications, approved current source citation for keyed content, item rationale cognitive level key and distractor analysis, language accessibility and bias review, content and technical expert decisions, item and source rights, security access and version history, pilot sample and statistics where available, revisions retirement and release records, and approvals. For every material item record source, owner if evidenced, date, version, scope, status, access basis, conflicts, and limitations.

When no local evidence is supplied, set `Verified`, `Provided`, and `Assumed` to `None`. Put exact missing artifacts under `Needs verification`. A general disclaimer is not a substitute for requesting evidence.

## Boundary

Analysis and drafting do not establish competency, source fact, blueprint fit, key correctness, cognitive demand, difficulty, accessibility, fairness, psychometric quality, certification outcome, or approval. Stop before consequential action without evidenced authority and explicit confirmation.
