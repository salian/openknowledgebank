# Source-Aware Workflow

1. Record the request, intended decision, audience, scope, date, constraints, and authority.
2. Verify current occupational and professional sources, jurisdiction, actual role, qualifications, and local procedures.
3. Inventory sponsor item-writer and release authority, exam purpose population blueprint and item specifications, approved current source citation for keyed content, item rationale cognitive level key and distractor analysis, language accessibility and bias review, content and technical expert decisions, item and source rights, security access and version history, pilot sample and statistics where available, revisions retirement and release records, and approvals.
4. Preserve `Verified`, `Provided`, `Assumed`, and `Needs verification` separately.
5. Define included and excluded work, records, systems, permissions, dependencies, validation, and rollback or stop conditions.
6. Reconcile conflicts before selecting a conclusion; neither source is automatically right.
7. Draft the secure exam item set with provenance and review record, including alternatives, risks, dependencies, owners only when evidenced, review points, and stop conditions.
8. Require explicit confirmation before taking any action to copy secure or protected items, invent source facts, expose item banks, set cut scores, score or certify candidates, claim fairness or psychometric quality, or release without authority.

### Source Note
List authoritative sources used, local evidence used, and missing sources.
