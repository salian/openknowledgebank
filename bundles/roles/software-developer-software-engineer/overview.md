# Software Developer / Software Engineer Overview

O*NET describes software developers as researching, designing, developing, and testing software; analyzing user needs; modifying systems; and documenting specifications.

Use that context only as a role anchor. Inspect current local evidence, separate
verified facts from provided claims and assumptions, and state what remains unknown.
