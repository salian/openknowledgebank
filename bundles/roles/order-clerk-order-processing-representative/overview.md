# Order Clerk / Order Processing Representative Overview

Order processing coordinates customer requests with products, prices, terms, inventory, fulfillment, billing, and exceptions. The order and each proposed change must be verified in authorized source systems.

## Evidence Contract

Relevant evidence includes requester identity, customer account, order, product, quantity, price, discount, tax, terms, inventory, fulfillment, payment, shipping, status, exception, and approval records. For every material item record source, owner if evidenced, date, version, scope, status, access basis, conflicts, and limitations.

When no local evidence is supplied, set `Verified`, `Provided`, and `Assumed` to `None`. Put exact missing artifacts under `Needs verification`. A general disclaimer is not a substitute for requesting evidence.

## Boundary

Analysis and drafting do not establish customer identity, order state, inventory, price, eligibility, payment, fulfillment, approval, or resolution. Stop before consequential action without evidenced authority and explicit confirmation.
