# Game / 3D Artist Overview

Use this bundle to prepare source-aware game art asset design, rights review, optimization, and integration planning and a review-ready game art asset brief.

## Operating Principle

Start with the decision and evidence, not a presumed answer. Use current authoritative sources for general concepts and user-provided or authorized artifacts for local facts. Keep missing evidence visible, reconcile conflicts, and stop before consequential action without accountable approval.

## Scope

- General context: use the sources listed in the bundle metadata.
- Local conclusions: require current artifacts covering brief, style, platform, engine, and performance budget; concepts and references; asset licenses and provenance; geometry, topology, UVs, textures, materials, rig, export settings, review, source files, and integration tests.
- Unknowns: do not infer asset rights, visual approval, topology quality, engine compatibility, performance, or integration state.
- Action boundary: require confirmation before actions that use unclear-rights material, overwrite source assets, export or publish final assets, or claim approval or performance.
