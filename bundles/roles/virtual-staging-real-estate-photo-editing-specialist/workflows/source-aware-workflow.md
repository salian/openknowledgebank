# Source-Aware Workflow

1. Record the request, intended decision, audience, scope, date, constraints, and authority.
2. Verify current occupational and professional sources, jurisdiction, actual role, qualifications, and local procedures.
3. Inventory client photographer and listing authority, original files and metadata, property and room identifiers, broker-approved edit brief, source-to-output comparison, object removal furnishing repair and structural-change ledger, required labels and disclosures, image asset model and font rights, privacy and release records, fair-housing review, export and listing tests, version history, and approvals.
4. Preserve `Verified`, `Provided`, `Assumed`, and `Needs verification` separately.
5. Define included and excluded work, records, systems, permissions, dependencies, validation, and rollback or stop conditions.
6. Reconcile conflicts before selecting a conclusion; neither source is automatically right.
7. Draft the disclosed virtual-staging image set and edit ledger, including alternatives, risks, dependencies, owners only when evidenced, review points, and stop conditions.
8. Require explicit confirmation before taking any action to edit without authority, remove material defects, fabricate structural features or views, depict discriminatory preferences, use unlicensed assets, overwrite originals, publish images, or represent property condition.
