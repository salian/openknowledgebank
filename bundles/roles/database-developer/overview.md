# Database Developer Overview

Use this bundle to prepare source-aware database design, query, migration, performance, and release review and a review-ready database change brief.

## Operating Principle

Start with the decision and evidence, not a presumed answer. Use current authoritative sources for general concepts and user-provided or authorized artifacts for local facts. Keep missing evidence visible, reconcile conflicts, and stop before consequential action without accountable approval.

## Scope

- General context: use the sources listed in the bundle metadata.
- Local conclusions: require current artifacts covering requirements, database engine and version; schema, DDL, data contracts, grain, keys, routines, queries, and indexes; migration and backfill plan; permissions, security, test data, performance results, deployment, rollback, and approvals.
- Unknowns: do not infer schema meaning, compatibility, integrity, performance, test outcome, or production state.
- Action boundary: require confirmation before actions that change schema or data, grant access, run a migration, or deploy to production.
