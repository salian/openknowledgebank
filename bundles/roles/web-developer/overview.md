# Web Developer Overview

Use this bundle to prepare source-aware web development and delivery analysis and a review-ready web delivery brief.

## Operating Principle

Start with the decision and evidence, not a presumed answer. Use current authoritative sources for general concepts and user-provided or authorized artifacts for local facts. Keep missing evidence visible, reconcile conflicts, and stop before consequential action without accountable approval.

## Scope

- General context: use the sources listed in the bundle metadata.
- Local conclusions: require current artifacts covering requirements, users, content, acceptance criteria, and supported platforms; repository, runtime, framework, dependencies, build, and environment versions; frontend and backend contracts, data, authentication, privacy, and security; responsive states, browser and device support, performance, SEO, and applicable WCAG criteria; tests, deployment, monitoring, rollback, rights, and approvals.
- Unknowns: do not infer browser behavior, compatibility, accessibility, security, performance, test outcome, or production state.
- Action boundary: require confirmation before deploying code, changing data or access, publishing content, using credentials, or claiming accessibility or security conformance.
