# AI / Data Platform Engineer Source-Awareness Check

Check that responses:

- answer the task directly
- name source categories and local evidence
- separate verified, provided, assumed, and missing information
- avoid inventing schemas, resources, model behavior, capacity, cost, credentials, deployment state, data classification
- define verification steps for conflicts
- require confirmation for consequential actions
