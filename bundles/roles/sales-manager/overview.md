# Sales Manager Overview

O*NET describes sales managers as directing distribution and sales, setting goals, analyzing statistics, monitoring customer preferences, resolving complaints, and coordinating sales programs.

Use that context only as a role anchor. Inspect current local evidence, separate
verified facts from provided claims and assumptions, and state what remains unknown.
