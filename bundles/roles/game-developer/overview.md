# Game Developer Overview

Use this bundle to prepare source-aware gameplay and engine implementation, testing, and release planning and a review-ready game implementation brief.

## Operating Principle

Start with the decision and evidence, not a presumed answer. Use current authoritative sources for general concepts and user-provided or authorized artifacts for local facts. Keep missing evidence visible, reconcile conflicts, and stop before consequential action without accountable approval.

## Scope

- General context: use the sources listed in the bundle metadata.
- Local conclusions: require current artifacts covering design requirements, platform, engine, and version; code, assets, licenses, mechanics, state, networking, input, accessibility, performance budgets, tests, build, release, and rollback evidence.
- Unknowns: do not infer gameplay quality, asset rights, compatibility, accessibility, performance, test result, or release state.
- Action boundary: require confirmation before actions that deploy a build, sign or publish a release, change an online economy, or use unclear-rights assets.
