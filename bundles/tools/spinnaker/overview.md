# Spinnaker Overview

## Scope

- Applications, clusters, server groups, load balancers, firewalls, pipelines, stages, artifacts, triggers, manual judgments, deployment strategies, rollbacks and supported cloud-provider integrations.
- Fiat authorization, accounts and credentials, notifications, webhooks, plugins, Halyard or Kleat and deployment-method lifecycle where applicable, observability, version compatibility, validation, and controlled delivery.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before connect cloud accounts, expose credentials, trigger pipelines, approve judgments, deploy or roll back services, change traffic or infrastructure, install plugins, or represent artifact provenance, stage success, availability, security, or release readiness without evidenced authority, validation, and explicit confirmation.
