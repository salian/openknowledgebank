# Harness Overview

## Scope

- Continuous integration and delivery, feature flags, infrastructure, cloud cost, security testing, supply-chain controls, incidents, templates, governance, and insights.
- Accounts, organizations, projects, connectors, secrets, roles, policies, approvals, audit evidence, validation, and rollback.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect account and modules, organizations and projects, connectors and secrets, services and environments, infrastructure, pipelines and artifacts, feature flags, policies and approvals, costs, findings, incidents, logs, tests, rollback, and approvals.

## Boundary

Stop before run pipelines, deploy code, change infrastructure or feature flags, expose secrets, approve policies, remediate findings, alter budgets, manage incidents, or represent delivery or security state without evidenced authority, validation, and explicit confirmation.
