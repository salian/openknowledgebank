# Trello Overview

## Scope

- Workspaces, boards, lists, cards, members, comments, checklists, labels, dates, custom fields, views, templates, notifications, sharing and exports according to plan.
- Butler automation, Power-Ups, integrations, REST API and webhooks, tokens and app keys, workspace and enterprise administration, permissions, audit evidence, limits, validation, rollback, and controlled work management.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before create or alter boards, cards, assignments or dates, run automations, install Power-Ups, share data, issue tokens, call APIs, change access, or represent ownership, priority, dependency, notification, delivery date, or completion without evidenced authority, validation, and explicit confirmation.
