# osTicket Overview

## Scope

- Tickets, users, organizations, agents, departments, teams, help topics, custom forms and fields, filters, SLAs, canned responses, tasks, knowledge base, and reports.
- Email fetching and piping, autoresponders, API ticket creation, plugins, authentication, permissions, audit evidence, self-hosted installation, upgrades, backups, security, validation, and recovery.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before create, assign, close or delete tickets, expose customer messages or attachments, send replies, change SLA or routing, install plugins, expose API keys, upgrade systems, or represent response, resolution, security, or availability without evidenced authority, validation, and explicit confirmation.
