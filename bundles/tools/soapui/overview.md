# SoapUI Open Source Overview

## Scope

- SOAP, REST and HTTP service projects, WSDL and supported OpenAPI imports, requests, test suites, test cases, assertions, properties, data-driven patterns, Groovy scripts, mocks and supported load checks.
- Command-line execution, CI integration, project files, environments and authentication configuration, open-source versus ReadyAPI distinctions, secrets handling, test isolation, evidence capture, validation, and controlled testing.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before send requests to systems, include credentials or production data, execute scripts, run load or security tests, expose project secrets, modify endpoints, or represent coverage, correctness, performance, vulnerability, or production readiness without evidenced authority, validation, and explicit confirmation.
