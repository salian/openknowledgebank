# Google Chat Overview

## Scope

- Direct messages, group messages, spaces, files, tasks, meetings, external collaboration, apps, APIs, and automation.
- Workspace administration, retention, permissions, migration, integrations, audit evidence, and validation.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect tenant and edition, spaces, users and membership, external access, messages and files, tasks, apps, OAuth scopes, retention, DLP, integrations, logs, tests, rollback, and approvals.

## Boundary

Stop before send or delete messages, create spaces, add external members, share files, assign tasks, install apps, grant scopes, migrate content, change retention, or represent delivery without evidenced authority, validation, and explicit confirmation.
