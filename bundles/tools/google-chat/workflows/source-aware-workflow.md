# Source-Aware Workflow

1. Record objective, account or project scope, date, constraints, and authorized owner.
2. Verify current official sources, edition, region, API or feature version, and lifecycle status.
3. Inspect tenant and edition, spaces, users and membership, external access, messages and files, tasks, apps, OAuth scopes, retention, DLP, integrations, logs, tests, rollback, and approvals.
4. Separate `Verified`, `Provided`, `Assumed`, and `Needs verification`.
5. Reconcile conflicts among documentation, configuration, permissions, data, integrations, and logs.
6. Draft the Google Chat collaboration and administration review brief with options, dependencies, privacy and security risks, validation, rollback, and stop conditions.
7. Require explicit confirmation before send or delete messages, create spaces, add external members, share files, assign tasks, install apps, grant scopes, migrate content, change retention, or represent delivery.
