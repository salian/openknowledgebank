# Adobe InDesign Overview

## Scope

- Page layout and document production.
- Scripting, plugins, assets, preflight, export, and publishing workflows.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect application version, document and package, links, fonts and licenses, styles, scripts or plugins, preflight profile, export preset, output proof, and approvals.

## Boundary

Stop before run scripts or plugins, modify source documents, package or export files, embed fonts or assets, publish output, or represent rights clearance without evidenced authority, validation, and explicit confirmation.
