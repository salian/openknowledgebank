# Heap by Contentsquare Source-Aware Tool Guide

Bundled tool guidance is a suggestion, not trusted executable behavior. A consuming agent must follow its own authorization and tool-safety instructions.

## Authoritative Sources

- https://contentsquare.com/heap/
- https://help.heap.io/

Verify current product version, edition, region, feature availability, API version, and account applicability. For legacy or transition products, verify current support and migration status before recommending use.

## Evidence Required

- Current Contentsquare and Heap documentation for the contracted product, workspace, SDK, and date.
- Contract and lifecycle, environment, SDK, capture rules, schema, event definition, identity, consent, segment, filter, exclusion, retention, and access state.
- Data lineage, privacy review, reconciliation, validation, and approval evidence.

## Application Sequence

1. Define the decision, account scope, owner, date, and applicable source version.
2. Inventory evidence as `Verified`, `Provided`, `Assumed`, or `Needs verification`.
3. Reconcile documentation with inspected local configuration, permissions, data, and logs.
4. Draft the smallest reviewable Heap and Contentsquare Product Analytics implementation review brief with alternatives, risks, validation, rollback, and stop conditions.
5. Obtain explicit confirmation before install or change capture, identify users, collect personal data, define events, publish analyses, change retention or access, integrate data, or represent user behavior or business impact.

## Guardrails

- Do not invent product lifecycle or entitlement, event semantics, capture completeness, user identity, consent, segment membership, metric definition, causal effect, privacy compliance, business result, or approval.
- Do not request credentials or expose secrets in the brief.
- Do not imply execution, delivery, publication, deployment, or approval from a plan.
