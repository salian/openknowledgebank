# DaVinci Resolve Overview

Source-aware guidance for DaVinci Resolve projects, media, color, audio, effects, collaboration, automation, and controlled delivery.

## Evidence Contract

Relevant evidence includes edition, version, operating system, project library, collaboration state, timelines, source media, authorship, licenses, consent, proxies, color management, effects, audio, captions, plugins, scripts, render settings, tests, owners, and approvals. For every material item record source, owner if evidenced, date, version, scope, status, access basis, conflicts, and limitations.

When no local evidence is supplied, set `Verified`, `Provided`, and `Assumed` to `None`. Put exact missing artifacts under `Needs verification`. A general disclaimer is not a substitute for requesting evidence.

## Boundary

Analysis and drafting do not establish Edition and version behavior, project contents, asset rights, consent, timeline state, plugin safety, color and audio accuracy, caption quality, render fidelity, and release authority. Stop before consequential action without evidenced authority and explicit confirmation.
