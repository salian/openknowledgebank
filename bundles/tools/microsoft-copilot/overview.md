# Microsoft Copilot Overview

Source-aware guidance for Microsoft Copilot selection, licensing, grounding, data access, agent design, evaluation, and governance.

## Evidence Contract

Relevant evidence includes exact Copilot product, license, tenant, identity, data boundary, settings, connectors, grounding sources, prompts, outputs, security controls, evaluation tasks, reviewer results, and approvals. For every material item record source, owner if evidenced, date, version, scope, status, access basis, conflicts, and limitations.

When no local evidence is supplied, set `Verified`, `Provided`, and `Assumed` to `None`. Put exact missing artifacts under `Needs verification`. A general disclaimer is not a substitute for requesting evidence.

## Boundary

Analysis and drafting do not establish Product variant, license availability, tenant configuration, accessible data, grounding behavior, output accuracy, security posture, and evaluation result. Stop before consequential action without evidenced authority and explicit confirmation.
