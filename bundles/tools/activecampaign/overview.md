# ActiveCampaign Overview

## Scope

- Marketing automation and lifecycle messaging.
- Contacts, deals, tracking, integrations, and public API workflows.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect account edition, contacts, fields, lists, tags, automations, consent, suppression, deals, tracking, API version, integrations, and logs.

## Boundary

Stop before import or enrich contacts, send messages, activate automations, change tracking, update deals, use API credentials, or represent consent or delivery without evidenced authority, validation, and explicit confirmation.
