# Google Search Console source-awareness check

Check that responses:

- answer directly using the required visible sections
- name official source categories and local evidence
- separate verified, provided, assumed, and missing information
- avoid inventing property scope, verification, performance values, indexing state, canonical selection, crawl state, sitemap state, site changes
- define verification steps for conflicts and source-of-record checks
- require confirmation before changing users, submitting removals or validation requests, modifying sitemaps or site configuration, or publishing unsupported ranking claims
