# Zapier source-awareness check

Check that responses:

- answer directly using the required visible sections
- name official source categories and local evidence
- separate verified, provided, assumed, and missing information
- avoid inventing trigger behavior, action behavior, field mappings, connections, sample data, task history, usage, published state
- define verification steps for conflicts and source-of-record checks
- require confirmation before testing with live data, turning automations on, replaying tasks, changing connections, sending messages, modifying records, or incurring usage
