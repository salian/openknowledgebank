# UiPath Overview

Source-aware guidance for UiPath automation design, credentials, selectors, data handling, orchestration, testing, and governed release.

## Evidence Contract

Relevant evidence includes product edition, version, tenant, folders, packages, processes, robots, machines, accounts, credentials, selectors, applications, queues, assets, schedules, logs, exception paths, tests, owners, and approvals. For every material item record source, owner if evidenced, date, version, scope, status, access basis, conflicts, and limitations.

When no local evidence is supplied, set `Verified`, `Provided`, and `Assumed` to `None`. Put exact missing artifacts under `Needs verification`. A general disclaimer is not a substitute for requesting evidence.

## Boundary

Analysis and drafting do not establish Product and tenant state, package behavior, credential scope, selector reliability, data values, run outcome, downstream effects, compliance, and authority. Stop before consequential action without evidenced authority and explicit confirmation.
