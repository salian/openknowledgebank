# Strapi Overview

## Scope

- Headless content management with collection and single types, components and dynamic zones, entries, media library, localization, drafts and publishing, users, roles and permissions.
- REST and GraphQL APIs where enabled, API tokens, webhooks, plugins, admin customization, database and deployment configuration, Strapi Cloud and self-hosted distinctions, version upgrades, backup, validation, and controlled publication.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before change schemas or content, publish entries, upload media, grant roles, issue tokens, install plugins, call APIs, deploy or upgrade instances, or represent schema, content state, permission, API result, migration, availability, security, or publication without evidenced authority, validation, and explicit confirmation.
