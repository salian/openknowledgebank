# Box Sign Overview

## Scope

- Electronic signature requests, templates, routing, signer roles, authentication, tracking, and executed-document retention.
- Batch send, ready-sign links, APIs, integrations, governance, reporting, and regulated signing workflows.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect Box plan and region, document version and ownership, signer identities and authority, recipient roles and order, consent and disclosure, fields, templates, authentication, jurisdiction and transaction type, retention, integrations, request events, and executed record.

## Boundary

Stop before send or cancel signature requests, create public signing links, authenticate signers, change documents or recipients, countersign, retain or delete executed agreements, or represent enforceability without evidenced authority, validation, and explicit confirmation.
