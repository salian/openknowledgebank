# SAP Business One Overview

## Scope

- General ledger, banking, sales, customers, purchasing, vendors, inventory, warehouses, production and MRP, service, projects, CRM, fixed assets, reports, dashboards, and approvals.
- SQL Server and SAP HANA deployment distinctions, localizations, add-ons, Integration Framework, Service Layer and DI API where applicable, users, authorizations, audit logs, upgrades, backups, migration, evidence, and controlled ERP operations.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before create, post or reverse transactions, change master data, inventory, pricing, tax or authorizations, approve purchases or payments, run MRP, deploy add-ons, call APIs, migrate or upgrade systems, or represent financial, inventory, tax, production, or compliance state without evidenced authority, validation, and explicit confirmation.
