# Source-Aware Workflow

1. Record objective, account or project scope, date, constraints, and authorized owner.
2. Verify current official sources, edition, region, API or feature version, and lifecycle status.
3. Inspect subscription, workspaces, partitions, person fields, consent, programs, smart campaigns, scoring, channels, integrations, permissions, and activity logs.
4. Separate `Verified`, `Provided`, `Assumed`, and `Needs verification`.
5. Reconcile conflicts among documentation, configuration, permissions, data, integrations, and logs.
6. Draft the Adobe Marketo Engage configuration and use review brief with options, dependencies, privacy and security risks, validation, rollback, and stop conditions.
7. Require explicit confirmation before import or update people, change scoring, activate campaigns, send communications, sync CRM data, export records, or represent consent or attribution.
