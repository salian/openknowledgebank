# DeepSeek API Overview

## Scope

- Chat and reasoning models, text generation, tool calls, structured output, context caching, and agent integrations.
- OpenAI- and Anthropic-compatible APIs, model selection, authentication, streaming, parameters, usage, evaluation, and operations.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current model and dated revision, API format and endpoint, account and region, data handling, credentials, prompts and system instructions, tool definitions and permissions, inputs and classifications, parameters, outputs, usage and cost, safety tests, evaluations, monitoring, and approvals.

## Boundary

Stop before send sensitive data, call production models or tools, expose credentials, automate decisions, publish generated content, change systems, or represent model output as factual or approved without evidenced authority, validation, and explicit confirmation.
