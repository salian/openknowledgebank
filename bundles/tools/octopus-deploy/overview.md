# Octopus Deploy Overview

## Scope

- Projects, deployment processes, packages, releases, channels, lifecycles, environments, targets, tenants, variables, certificates, accounts, and approvals.
- Runbooks, workers, spaces, permissions, audit logs, Config as Code where applicable, REST API and CLI automation, Kubernetes and cloud deployment, observability, rollback, backup, and upgrades.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before create or deploy releases, run runbooks, change variables, secrets, targets, lifecycles or permissions, call production APIs, execute scripts, promote packages, upgrade servers, or represent deployment, rollback, security, or service health without evidenced authority, validation, and explicit confirmation.
