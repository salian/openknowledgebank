# Blueshift Overview

## Scope

- Customer profiles, events, catalogs, audiences, journeys, campaigns, recommendations, and cross-channel engagement.
- APIs, SDKs, authentication, data ingestion, identity, messaging, integrations, and reporting.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect account, region and edition, API version and credentials, customer identifiers, event and catalog schemas, consent and suppression, identity rules, audiences, journeys, campaigns, templates, channels, recommendations, integrations, attribution, and logs.

## Boundary

Stop before ingest or export customer data, merge identities, create or activate audiences or journeys, send messages, change consent or suppression, use credentials, or represent campaign outcomes without evidenced authority, validation, and explicit confirmation.
