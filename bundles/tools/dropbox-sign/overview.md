# Dropbox Sign Overview

## Scope

- Electronic signature requests, templates, embedded signing, signer routing, tracking, and executed-document workflows.
- API applications, authentication, callbacks, branding, teams, audit trails, integrations, and document retention.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect plan and API version, application and credentials, document version and ownership, signer identities and authority, recipient roles and order, consent and disclosure, fields and templates, authentication, jurisdiction and transaction type, callbacks, retention, request events, and executed record.

## Boundary

Stop before send or cancel signature requests, create embedded or public signing flows, change documents or recipients, authenticate signers, countersign, expose API credentials, retain or delete records, or represent enforceability without evidenced authority, validation, and explicit confirmation.
