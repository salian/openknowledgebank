# Source-Aware Workflow

1. Record objective, account or project scope, date, constraints, and authorized owner.
2. Verify current official sources, edition, region, API or feature version, and lifecycle status.
3. Inspect installed version and edition, operating system and hardware, project ownership, source recordings and releases, samples and licenses, tracks and routing, tempo and synchronization, plug-ins and versions, MIDI and score data, mix and mastering settings, export specification, renders, and quality-control results.
4. Separate `Verified`, `Provided`, `Assumed`, and `Needs verification`.
5. Reconcile conflicts among documentation, configuration, permissions, data, integrations, and logs.
6. Draft the Steinberg Cubase configuration and use review brief with options, dependencies, privacy and security risks, validation, rollback, and stop conditions.
7. Require explicit confirmation before record or overwrite media, install untrusted plug-ins, modify shared projects, render or export masters, publish audio, use licensed content, or represent rights or quality approval.
