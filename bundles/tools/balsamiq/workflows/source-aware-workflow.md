# Source-Aware Workflow

1. Record objective, account or project scope, date, constraints, and authorized owner.
2. Verify current official sources, edition, region, API or feature version, and lifecycle status.
3. Inspect product and edition, workspace, project and ownership, collaborators and permissions, source requirements, components and assets, links, comments, version history, exports, accessibility review, and approval records.
4. Separate `Verified`, `Provided`, `Assumed`, and `Needs verification`.
5. Reconcile conflicts among documentation, configuration, permissions, data, integrations, and logs.
6. Draft the Balsamiq configuration and use review brief with options, dependencies, privacy and security risks, validation, rollback, and stop conditions.
7. Require explicit confirmation before create or overwrite wireframes, share projects, invite collaborators, publish links, export confidential designs, use third-party assets, or represent design approval.
