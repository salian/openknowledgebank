# Affinity Overview

## Scope

- Vector, photo, and layout design workflows.
- Creative documents, assets, typography, export, and current Canva-era product transition.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product build and licensing terms, document type, assets, fonts, links, color settings, export requirements, product transition status, and approvals.

## Boundary

Stop before install or update software, modify source files, use unlicensed assets, export or publish work, migrate documents, or represent rights clearance without evidenced authority, validation, and explicit confirmation.
