# Redmine Overview

## Scope

- Projects, subprojects, issues, trackers, statuses, priorities, categories, versions, roadmaps, calendars, Gantt charts, time entries, custom fields, documents, files, wikis, forums, and repository integration.
- Roles and permissions, workflows, email, notifications, authentication, plugins and themes, REST API, imports, exports, administration, installation, upgrades, backups, audit evidence, validation, and recovery.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before create or alter issues, projects, time entries, workflows or permissions, send email, install plugins, expose API keys, change repositories, upgrade systems, restore backups, or represent status, effort, delivery, security, or availability without evidenced authority, validation, and explicit confirmation.
