# Snowflake source-awareness check

Check that responses:

- answer directly using the required visible sections
- name official source categories and local evidence
- separate verified, provided, assumed, and missing information
- avoid inventing objects, columns, data, roles, grants, warehouse state, query results, cost
- define verification steps for conflicts and source-of-record checks
- require confirmation before running state-changing SQL, changing objects, warehouses, roles, grants, policies, integrations, shares, or production data
