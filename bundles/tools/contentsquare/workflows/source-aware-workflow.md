# Source-Aware Workflow

1. Record objective, account or project scope, date, constraints, and authorized owner.
2. Verify current official sources, edition, region, API or feature version, and lifecycle status.
3. Inspect subscription and modules, sites and apps, capture method, consent and privacy settings, masking, identities, sessions, events, journeys, errors, metrics, filters, experiments, integrations, MCP scopes, AI settings, retention, and reports.
4. Separate `Verified`, `Provided`, `Assumed`, and `Needs verification`.
5. Reconcile conflicts among documentation, configuration, permissions, data, integrations, and logs.
6. Draft the Contentsquare configuration and use review brief with options, dependencies, privacy and security risks, validation, rollback, and stop conditions.
7. Require explicit confirmation before enable capture or replay, change masking or consent settings, connect MCP or data sources, export user data, activate experiments, publish recommendations, or represent behavior or conversion outcomes.
