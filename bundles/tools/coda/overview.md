# Superhuman Docs (formerly Coda) Overview

## Scope

- Collaborative documents, pages, tables, formulas, controls, packs, automations, sharing, and publishing under the current Superhuman Docs name.
- REST API and MCP access, workspaces, folders, rows, permissions, integrations, mutation status, versioning, and automation.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product naming and migration status, workspace and plan, documents and ownership, pages and tables, formulas and controls, packs and automations, collaborators and permissions, API or MCP scopes, row and snapshot versions, queued mutation status, integrations, publishing, and audit history.

## Boundary

Stop before create, update, share, publish or delete docs, pages, tables or rows, run automations, install packs, connect API or MCP, expose data, or represent queued writes as complete without evidenced authority, validation, and explicit confirmation.
