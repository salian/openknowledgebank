# OpenText Vertica Overview

## Scope

- Columnar analytic database schemas, tables, views, projections, data loading and export, SQL analytics, functions, resource pools, workload management, monitoring, auditing and administration.
- Enterprise Mode and Eon Mode architecture distinctions, supported deployment environments and object storage, security and encryption, integrations and SDKs, version compatibility, upgrades, backup and restore, recovery, performance validation, and controlled production operations.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before connect or expose data, execute queries or DDL, load or delete records, alter projections, privileges or resource pools, upgrade clusters, back up or restore data, or represent schema, query, performance, durability, security, availability, or recovery without evidenced authority, validation, and explicit confirmation.
