# Sonatype Nexus Repository Overview

## Scope

- Hosted, proxy and group repositories for supported package formats, components and assets, search, routing, content selectors, cleanup policies, blob stores, replication and staging capabilities where licensed.
- Repository 3 deployment and upgrade lifecycle, the retired Repository 2 boundary, roles and privileges, authentication, tokens, REST APIs, webhooks, backup and restore, high availability where licensed, validation, and controlled artifact operations.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before publish or delete artifacts, proxy external sources, change routing or cleanup, grant privileges, expose tokens, migrate or upgrade repositories, restore data, or represent provenance, integrity, vulnerability, availability, compatibility, or release approval without evidenced authority, validation, and explicit confirmation.
