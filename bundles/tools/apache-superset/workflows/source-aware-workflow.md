# Source-Aware Workflow

1. Record objective, account or project scope, date, constraints, and authorized owner.
2. Verify current official sources, edition, region, API or feature version, and lifecycle status.
3. Inspect deployed version, enabled features, database connections, datasets, SQL queries, dashboards, roles, row-level security, caches, embeds, and logs.
4. Separate `Verified`, `Provided`, `Assumed`, and `Needs verification`.
5. Reconcile conflicts among documentation, configuration, permissions, data, integrations, and logs.
6. Draft the Apache Superset configuration and use review brief with options, dependencies, privacy and security risks, validation, rollback, and stop conditions.
7. Require explicit confirmation before connect databases, execute SQL, publish dashboards, change roles or row-level security, enable embeds, or represent metrics as validated.
