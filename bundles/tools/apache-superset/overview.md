# Apache Superset Overview

## Scope

- Data exploration, charting, dashboards, semantic datasets, and SQL workflows.
- Authentication, authorization, database connections, APIs, embedding, and administrative configuration.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect deployed version, enabled features, database connections, datasets, SQL queries, dashboards, roles, row-level security, caches, embeds, and logs.

## Boundary

Stop before connect databases, execute SQL, publish dashboards, change roles or row-level security, enable embeds, or represent metrics as validated without evidenced authority, validation, and explicit confirmation.
