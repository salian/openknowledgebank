# Source-Aware Workflow

1. Record objective, account or project scope, date, constraints, and authorized owner.
2. Verify current official sources, edition, region, API or feature version, and lifecycle status.
3. Inspect instance, groups, portfolios, projects, templates, assignments, rates, forms, proofs, approvals, permissions, integrations, and audit history.
4. Separate `Verified`, `Provided`, `Assumed`, and `Needs verification`.
5. Reconcile conflicts among documentation, configuration, permissions, data, integrations, and logs.
6. Draft the Adobe Workfront configuration and use review brief with options, dependencies, privacy and security risks, validation, rollback, and stop conditions.
7. Require explicit confirmation before create or reassign work, change schedules or rates, approve proofs, alter permissions, integrate systems, or represent completion or approval.
