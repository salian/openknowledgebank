# SuiteCRM Overview

## Scope

- Open-source CRM modules for accounts, contacts, leads, opportunities, activities, cases, campaigns, projects, documents, reports and workflows, plus configurable fields, layouts, roles and security groups.
- SuiteCRM 8 administration and customization, API V8 and legacy API distinctions, OAuth2, extensions, self-hosted deployment, upgrades, backups, email and other integrations, audit evidence, validation, rollback, and controlled CRM operations.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before import or identify people, send communications, change sales or service records, run workflows, issue OAuth credentials, call APIs, install customizations, deploy or upgrade systems, or represent consent, pipeline, forecast, case resolution, migration, security, or compliance without evidenced authority, validation, and explicit confirmation.
