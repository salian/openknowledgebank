# OpenRouter Overview

## Scope

- Unified access to multiple model providers, chat completions and supported response surfaces, streaming, structured outputs, tool calling, reasoning controls, multimodal requests, and model routing.
- Provider preferences, fallbacks, data and privacy settings, API keys, OAuth where documented, usage and generation metadata, rate limits, credits, model lifecycle, observability, and cost governance.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before send confidential data to model providers, expose keys, select or route providers, invoke tools, spend credits, log prompts or outputs, publish generated claims, or represent model identity, privacy, accuracy, safety, latency, or cost without evidenced authority, validation, and explicit confirmation.
