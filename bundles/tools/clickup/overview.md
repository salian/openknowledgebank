# ClickUp Overview

## Scope

- Spaces, folders, lists, tasks, docs, goals, time, comments, views, automations, and reporting.
- Public API, MCP server, webhooks, OAuth, integrations, users, teams, permissions, and administrative workflows.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect workspace and plan, hierarchy and identifiers, users and teams, tasks and dependencies, docs and files, time and goals, custom fields and statuses, permissions, automations, API or MCP scopes, webhooks, integrations, retention, and audit history.

## Boundary

Stop before create or change tasks, docs, goals, time, users, permissions or automations, upload or delete files, connect OAuth, invoke MCP or API writes, or represent completion without evidenced authority, validation, and explicit confirmation.
