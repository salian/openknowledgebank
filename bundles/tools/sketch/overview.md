# Sketch Overview

## Scope

- Vector design, artboards, symbols and components, shared styles, libraries, prototyping, responsive layout, assets, exports, document history, comments, and collaboration.
- Browser inspection and developer handoff, workspace roles, sharing, templates, plugins, JavaScript API, command-line tools where documented, version compatibility, rights review, validation, and controlled release.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before upload confidential designs, change shared libraries, publish documents, install plugins, execute scripts, grant access, export protected assets, or represent authorship, rights, accessibility, implementation fidelity, review, or approval without evidenced authority, validation, and explicit confirmation.
