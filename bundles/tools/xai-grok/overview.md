# Grok and xAI API Overview

## Scope

- Text and multimodal models, chat, files, collections, web and X search, code interpreter, function calling, structured outputs, voice, image, and video.
- API authentication, model lifecycle, tool permissions, data handling, observability, evaluation, and controlled deployment.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect account and region, model and endpoint, parameters and prompts, files and collections, tools and functions, search sources, outputs and citations, usage, retention, logs, evaluations, human review, rollback, and approvals.

## Boundary

Stop before upload sensitive data, enable search or code execution, call functions, publish generated content, make consequential decisions, deploy an agent, incur spend, or represent factuality, safety, or completion without evidenced authority, validation, and explicit confirmation.
