# Source-Aware Workflow

1. Record objective, account or project scope, date, constraints, and authorized owner.
2. Verify current official sources, edition, region, API or feature version, and lifecycle status.
3. Inspect account and region, model and endpoint, parameters and prompts, files and collections, tools and functions, search sources, outputs and citations, usage, retention, logs, evaluations, human review, rollback, and approvals.
4. Separate `Verified`, `Provided`, `Assumed`, and `Needs verification`.
5. Reconcile conflicts among documentation, configuration, permissions, data, integrations, and logs.
6. Draft the Grok and xAI API implementation and risk review brief with options, dependencies, privacy and security risks, validation, rollback, and stop conditions.
7. Require explicit confirmation before upload sensitive data, enable search or code execution, call functions, publish generated content, make consequential decisions, deploy an agent, incur spend, or represent factuality, safety, or completion.
