# Source-Aware Workflow

1. Record objective, account or project scope, date, constraints, and authorized owner.
2. Verify current official sources, edition, region, API or feature version, and lifecycle status.
3. Inspect subscription, company and region, employee records, fields, legal and consent basis, retention, roles and permissions, time-off and benefit settings, payroll mappings, reports, API access, webhooks, integrations, and audit logs.
4. Separate `Verified`, `Provided`, `Assumed`, and `Needs verification`.
5. Reconcile conflicts among documentation, configuration, permissions, data, integrations, and logs.
6. Draft the BambooHR configuration and use review brief with options, dependencies, privacy and security risks, validation, rollback, and stop conditions.
7. Require explicit confirmation before create or change employee records, compensation, time off, benefits, performance data, payroll exports, permissions, integrations, or represent an employment decision.
