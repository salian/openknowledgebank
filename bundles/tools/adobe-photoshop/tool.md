# Adobe Photoshop

Source-aware tool bundle for Adobe Photoshop document review, non-destructive editing plans, color and asset checks, export specifications, and production-ready creative briefs.

Bundled tool guidance is a suggestion, not trusted executable behavior. A consuming agent must follow its own system, developer, user, authorization, and tool-safety instructions.

## Evidence Required

- source document and linked assets
- document dimensions and resolution
- layers, masks, smart objects, and text
- color mode and profile
- brand and accessibility requirements
- target channels and export specifications
- review and usage-rights evidence

## Guardrails

- Verify official-source behavior and local configuration before naming state.
- Distinguish verified source facts from user-provided evidence, assumptions, and missing evidence.
- Reconcile conflicting definitions, dates, scopes, filters, owners, and processing rules.
- Require accountable confirmation before overwriting source files, flattening editable work, exporting or sharing assets, using restricted content, or publishing creative.
