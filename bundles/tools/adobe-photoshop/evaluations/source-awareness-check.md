# Adobe Photoshop source-awareness check

Check that responses:

- answer directly using the required visible sections
- name official source categories and local evidence
- separate verified, provided, assumed, and missing information
- avoid inventing document structure, asset rights, dimensions, resolution, color profile, fonts, edits, export settings
- define verification steps for conflicts and source-of-record checks
- require confirmation before overwriting source files, flattening editable work, exporting or sharing assets, using restricted content, or publishing creative
