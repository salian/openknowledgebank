# Zeplin Overview

## Scope

- Projects and workspaces, screens and versions, components and styleguides, colors and text styles, assets and code snippets, flows and journeys, annotations, comments, review and developer handoff.
- Design-tool imports, connected components and repository links, integrations, apps, extensions, webhooks and APIs where supported, roles and permissions, version history, rights, accessibility evidence, validation, and controlled implementation handoff.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before upload confidential designs, publish versions, connect repositories, install extensions, execute integrations, expose tokens, grant access, export assets, or represent authorship, design-system state, implementation fidelity, accessibility, rights, or approval without evidenced authority, validation, and explicit confirmation.
