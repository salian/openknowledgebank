# Contentful Overview

## Scope

- Content models, entries, assets, environments, localization, delivery, preview, management, images, and GraphQL APIs.
- Spaces, organizations, roles, workflows, releases, webhooks, apps, integrations, tokens, publishing, and migration operations.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect plan and API version, organization and spaces, environments and aliases, content types and validations, entries and assets, locales, references, workflows and releases, users and roles, tokens and scopes, apps and webhooks, caches and delivery settings, migrations, version conflicts, and audit logs.

## Boundary

Stop before create or alter content models, entries, assets or environments, issue tokens, install apps, run migrations, publish, unpublish or delete content, change roles, or represent delivery without evidenced authority, validation, and explicit confirmation.
