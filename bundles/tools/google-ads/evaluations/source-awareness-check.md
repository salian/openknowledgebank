# Google Ads source-awareness check

Check that responses:

- answer directly using the required visible sections
- name official source categories and local evidence
- separate verified, provided, assumed, and missing information
- avoid inventing campaign state, spend, bids, budgets, conversion definitions, targeting, performance, attribution
- define verification steps for conflicts and source-of-record checks
- require confirmation before publishing ads, changing targeting, budgets, bids, conversion actions, experiments, billing, or account access
