# Greenhouse Overview

Source-aware guidance for Greenhouse recruiting data, workflows, APIs, webhooks, permissions, fairness review, and governed change.

## Evidence Contract

Relevant evidence includes organization, products, API generation and version, jobs, candidates, applications, stages, interviews, scorecards, assessments, users, roles, API keys and permissions, webhooks, data retention, fairness evidence, tests, owners, and approvals. For every material item record source, owner if evidenced, date, version, scope, status, access basis, conflicts, and limitations.

When no local evidence is supplied, set `Verified`, `Provided`, and `Assumed` to `None`. Put exact missing artifacts under `Needs verification`. A general disclaimer is not a substitute for requesting evidence.

## Boundary

Analysis and drafting do not establish Product and API availability, candidate facts, effective permissions, workflow outcomes, score validity, assessment fairness, privacy and retention, legal compliance, and hiring authority. Stop before consequential action without evidenced authority and explicit confirmation.
