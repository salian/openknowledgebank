# Insomnia Overview

## Scope

- HTTP, GraphQL, gRPC and WebSocket requests, environments, authentication, API specs, linting, collections, scripts, tests, and mocks.
- Imports, exports, Git synchronization, Inso CLI automation, storage options, vault integration, AI assistance, and organization administration.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before send requests to live systems, expose credentials, run scripts or tests, create public mocks, synchronize repositories, export data, change API specifications, or represent test or service results without evidenced authority, validation, and explicit confirmation.
