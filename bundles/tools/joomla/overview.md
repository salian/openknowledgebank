# Joomla Overview

## Scope

- Articles, modules, media, menus, custom fields, multilingual content, workflows, templates, extensions, SEO, version history, and accessibility.
- Users, access control, MFA, passwordless login, updates, caching, CDN configuration, backups, evidence, validation, and controlled publishing.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before install or update Joomla, extensions or templates, edit or publish content, change access, authentication, URLs or caching, run migrations, restore backups, or represent security or availability without evidenced authority, validation, and explicit confirmation.
