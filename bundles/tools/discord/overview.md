# Discord Developer Platform Overview

## Scope

- Servers, channels, messages, members, roles, interactions, bots, activities, and application integrations.
- Developer applications, OAuth2, gateway events, webhooks, permissions, moderation, commands, rate limits, and operational controls.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect application and API version, server and channel scope, users and roles, OAuth scopes, bot token references, intents and events, commands and interactions, webhooks, message and moderation policy, consent and retention, rate limits, permissions, test environment, and logs.

## Boundary

Stop before create or install applications or bots, issue tokens, read or send messages, change roles or moderation, access member data, invoke webhooks, or represent delivery or authorization without evidenced authority, validation, and explicit confirmation.
