# Sourcetree Overview

## Scope

- Graphical Git workflows for cloning, staging, committing, branching, merging, rebasing, stashing, tagging, remotes, logs, diffs, searching, submodules and supported Git LFS operations.
- Hosting-service connections, account and credential configuration, custom actions and embedded terminal surfaces where supported, Windows and macOS differences, conflict review, backup, validation, rollback, and controlled repository changes.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before clone private repositories, stage or commit files, rewrite history, merge or rebase branches, push, force push, change remotes, store credentials, run custom actions, or represent conflict resolution, synchronization, deployment, or approval without evidenced authority, validation, and explicit confirmation.
