# Intercom Source-Awareness Check

Check that responses:

- answer directly using the required visible sections
- name official or primary source categories and local evidence
- separate verified, provided, assumed, and missing information
- avoid inventing conversation state, routing behavior, customer identity, report meaning, automation outcome, and access rights
- define verification steps for conflicts and source-of-record checks
- require confirmation before sending or replying, changing routing or workflows, publishing help content, exporting personal data, or changing permissions
