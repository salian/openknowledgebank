# Prismic Overview

## Scope

- Repositories, pages, custom types, slices, Slice Machine, components, content fields, media, localization, releases, previews, scheduling, roles, and collaboration.
- Content API and client libraries, migration and management surfaces where documented, webhooks, integrations, Next.js and framework tooling, environments, permissions, evidence, validation, and controlled publication.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before change content models, create or alter content, publish releases, upload protected media, run migrations, trigger webhooks, expose tokens, change access, deploy sites, or represent content, translation, preview, delivery, SEO, or availability without evidenced authority, validation, and explicit confirmation.
