# Source-Aware Workflow

1. Record objective, account or project scope, date, constraints, and authorized owner.
2. Verify current official sources, edition, region, API or feature version, and lifecycle status.
3. Inspect installed version and edition, hardware and codecs, project and bin ownership, source media, licenses and releases, sequence state, color and audio settings, effects, linked storage, collaboration locks, export specification, renders, and quality-control results.
4. Separate `Verified`, `Provided`, `Assumed`, and `Needs verification`.
5. Reconcile conflicts among documentation, configuration, permissions, data, integrations, and logs.
6. Draft the Avid Media Composer configuration and use review brief with options, dependencies, privacy and security risks, validation, rollback, and stop conditions.
7. Require explicit confirmation before modify shared projects or sequences, relink or delete media, render or export masters, publish content, overwrite files, or represent rights or quality approval.
