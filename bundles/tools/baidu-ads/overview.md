# Baidu Ads Overview

## Scope

- Baidu advertising account, campaign, creative, audience, reporting, and conversion workflows.
- Official SDK-backed API integration, authentication, data access, and automation.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current Baidu Ads product and API availability, account and region, credentials and scopes, campaigns, budgets, bids, creatives, audiences, consent, conversions, tracking, policies, reports, attribution settings, and logs.

## Boundary

Stop before create or modify campaigns, budgets, bids, creatives, audiences, conversion tracking, upload customer data, call production APIs, or represent performance without evidenced authority, validation, and explicit confirmation.
