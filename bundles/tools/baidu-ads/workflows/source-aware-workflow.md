# Source-Aware Workflow

1. Record objective, account or project scope, date, constraints, and authorized owner.
2. Verify current official sources, edition, region, API or feature version, and lifecycle status.
3. Inspect current Baidu Ads product and API availability, account and region, credentials and scopes, campaigns, budgets, bids, creatives, audiences, consent, conversions, tracking, policies, reports, attribution settings, and logs.
4. Separate `Verified`, `Provided`, `Assumed`, and `Needs verification`.
5. Reconcile conflicts among documentation, configuration, permissions, data, integrations, and logs.
6. Draft the Baidu Ads configuration and use review brief with options, dependencies, privacy and security risks, validation, rollback, and stop conditions.
7. Require explicit confirmation before create or modify campaigns, budgets, bids, creatives, audiences, conversion tracking, upload customer data, call production APIs, or represent performance.
