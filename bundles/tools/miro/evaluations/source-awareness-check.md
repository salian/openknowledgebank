# Miro source-awareness check

Check that responses:

- answer directly using the required visible sections
- name official source categories and local evidence
- separate verified, provided, assumed, and missing information
- avoid inventing board content, object state, owner, participants, permissions, public links, integrations, export state
- define verification steps for conflicts and source-of-record checks
- require confirmation before editing or deleting board content, inviting users, changing sharing, publishing links, exporting sensitive content, or running unapproved workshops
