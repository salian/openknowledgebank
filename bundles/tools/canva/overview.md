# Canva Overview

Source-aware guidance for Canva designs, brand assets, Connect API integrations, exports, permissions, licensing, and controlled release.

## Evidence Contract

Relevant evidence includes plan, team, brand kit, design IDs, templates, assets, authorship, licenses, consent, fonts, dimensions, accessibility criteria, app registration, OAuth scopes, API version, exports, tests, owners, and approvals. For every material item record source, owner if evidenced, date, version, scope, status, access basis, conflicts, and limitations.

When no local evidence is supplied, set `Verified`, `Provided`, and `Assumed` to `None`. Put exact missing artifacts under `Needs verification`. A general disclaimer is not a substitute for requesting evidence.

## Boundary

Analysis and drafting do not establish Plan and API availability, design contents, asset rights, consent, brand approval, accessibility, effective permissions, export fidelity, and release authority. Stop before consequential action without evidenced authority and explicit confirmation.
