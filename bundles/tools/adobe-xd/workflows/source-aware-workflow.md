# Source-Aware Workflow

1. Record objective, account or project scope, date, constraints, and authorized owner.
2. Verify current official sources, edition, region, API or feature version, and lifecycle status.
3. Inspect current Adobe lifecycle notice, installed version, document ownership, libraries, links, plugins, prototype state, exports, migration target, and approvals.
4. Separate `Verified`, `Provided`, `Assumed`, and `Needs verification`.
5. Reconcile conflicts among documentation, configuration, permissions, data, integrations, and logs.
6. Draft the Adobe XD configuration and use review brief with options, dependencies, privacy and security risks, validation, rollback, and stop conditions.
7. Require explicit confirmation before recommend new adoption without lifecycle verification, run plugins, modify or export files, migrate assets, publish prototypes, or represent migration completeness.
