# Adobe XD Overview

## Scope

- Legacy interface design and prototyping artifacts.
- Plugin and UXP context, prototypes, exports, and migration assessment.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current Adobe lifecycle notice, installed version, document ownership, libraries, links, plugins, prototype state, exports, migration target, and approvals.

## Boundary

Stop before recommend new adoption without lifecycle verification, run plugins, modify or export files, migrate assets, publish prototypes, or represent migration completeness without evidenced authority, validation, and explicit confirmation.
