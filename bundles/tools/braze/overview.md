# Braze Overview

## Scope

- Customer profiles, segmentation, messaging, journeys, personalization, experimentation, and analytics.
- SDK and API data collection, identity, consent, channels, Canvas orchestration, catalogs, integrations, and reporting.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect workspace and region, SDK and API versions, user identifiers, events and attributes, consent and subscriptions, identity rules, segments, campaigns and Canvases, templates, channels, frequency and quiet-time settings, experiments, integrations, reports, and logs.

## Boundary

Stop before collect or export user data, merge identities, change subscriptions, activate segments or journeys, send messages, run experiments, use credentials, or represent engagement results without evidenced authority, validation, and explicit confirmation.
