# Plausible Analytics Overview

## Scope

- Pageviews, visitors, sources, campaigns, pages, devices, geography, real-time reports, filters, segments, comparisons, goals, funnels, user journeys, custom events and properties, and ecommerce revenue.
- Cloud and self-hosted scope where applicable, lightweight tracking, imports and exports, shared links, teams, SSO, Stats API v2, Events and Sites APIs, privacy claims, evidence, and controlled measurement.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before install tracking, send events or revenue, import or delete data, expose dashboards or API keys, change goals or access, query or export analytics, or represent anonymity, consent requirements, attribution, conversion, or revenue without evidenced authority, validation, and explicit confirmation.
