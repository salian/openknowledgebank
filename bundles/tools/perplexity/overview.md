# Perplexity Overview

## Scope

- Consumer and enterprise answer and research experiences where available, web search, citations, source discovery, file and collection workflows, and sharing.
- Sonar and other documented API models, search controls, recency and domain filters, structured outputs, streaming, usage and billing, API keys, privacy modes, evaluation, evidence reconciliation, and controlled publication.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before submit confidential data, call paid APIs, rely on retrieved sources, publish generated claims, share research, expose keys, automate decisions, or represent source authority, citation support, completeness, accuracy, privacy, or cost without evidenced authority, validation, and explicit confirmation.
