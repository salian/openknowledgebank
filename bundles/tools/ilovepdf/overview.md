# iLovePDF Overview

## Scope

- Merge, split, compress, convert, edit, organize, protect, unlock, sign, OCR, and repair PDF files.
- Web, desktop, mobile and REST API workflows, cloud storage connections, batch processing, evidence, validation, and controlled document handling.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before upload confidential files, alter or redact documents, apply or remove protection, OCR content, request signatures, connect storage, delete originals, or represent legal effect or document integrity without evidenced authority, validation, and explicit confirmation.
