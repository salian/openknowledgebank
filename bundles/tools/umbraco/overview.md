# Umbraco Overview

## Scope

- Content and document types, properties, templates and rendering, media, localization, previews and publishing, users and groups, workflows and forms where licensed.
- Open-source CMS, Umbraco Cloud and Heartcore distinctions, Content Delivery and Management APIs where applicable, packages and extensions, environments and deployment, version support, upgrades, backup, security, validation, rollback, and controlled publication.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before change content models or content, publish pages, install packages, issue API credentials, deploy or upgrade environments, restore backups, grant access, or represent version support, content state, package safety, migration, accessibility, security, or publication without evidenced authority, validation, and explicit confirmation.
