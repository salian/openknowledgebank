# Microsoft Clarity Overview

## Scope

- Session recordings, heatmaps, rage and dead-click insights, JavaScript errors, funnels, smart events, filters, segments, dashboard metrics, and exports.
- Installation, consent signals, masking, team permissions, Google Analytics integration, Copilot summaries, mobile SDKs, APIs where documented, privacy review, and retention evidence.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before install tracking, record sessions, collect or reveal user data, change masking or consent configuration, invite users, export data, connect integrations, or represent behavior, causality, conversion, privacy, or compliance without evidenced authority, validation, and explicit confirmation.
