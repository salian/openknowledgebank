# YouTrack Overview

## Scope

- Projects, issues and custom fields, searches and saved queries, agile boards and sprints, helpdesk tickets and channels, knowledge base, time tracking, reports, dashboards and notifications.
- No-code and JavaScript workflows, apps and integrations, REST API and webhooks, Cloud and Server distinctions, identities and permissions, imports and exports, backup and upgrade, audit evidence, validation, rollback, and controlled work tracking.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before create or alter issues, tickets, workflows or permissions, send notifications, execute scripts, connect systems, expose tokens, call APIs, migrate data, or represent state, priority, estimate, SLA, dependency, delivery date, or completion without evidenced authority, validation, and explicit confirmation.
