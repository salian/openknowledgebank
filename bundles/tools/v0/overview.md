# v0 Overview

## Scope

- Prompt- and context-driven generation and iteration of application interfaces and code, projects, files, previews, version history, imports and integrations according to current service capabilities.
- Vercel deployment and project connections, supported frameworks and packages, environment variables and data integrations, team sharing, usage and billing, generated-code review, licenses and provenance, accessibility, testing, security validation, and controlled release.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before upload proprietary code or data, expose secrets, install packages, connect services, generate or modify code, deploy applications, spend funds, or represent authorship, license, correctness, accessibility, security, deployment, or production readiness without evidenced authority, validation, and explicit confirmation.
