# Make Overview

Source-aware guidance for Make scenario design, integrations, data mapping, operations, error handling, and controlled activation.

## Evidence Contract

Relevant evidence includes organization, team, scenario, module versions, connections, credential scopes, source and target schemas, mappings, filters, schedules, error handlers, run history, operation costs, owners, and approvals. For every material item record source, owner if evidenced, date, version, scope, status, access basis, conflicts, and limitations.

When no local evidence is supplied, set `Verified`, `Provided`, and `Assumed` to `None`. Put exact missing artifacts under `Needs verification`. A general disclaimer is not a substitute for requesting evidence.

## Boundary

Analysis and drafting do not establish Module capability, scenario configuration, credential scope, data values, schedule, run outcome, downstream effects, and cost. Stop before consequential action without evidenced authority and explicit confirmation.
