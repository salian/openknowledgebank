# Smartsheet Overview

## Scope

- Sheets, rows, columns, formulas, forms, reports, dashboards, attachments, comments, sharing, alerts, approval and update workflows, templates, resource management and portfolio surfaces where licensed.
- Control Center, Dynamic View, Data Shuttle and other premium capabilities where licensed, connectors, REST API and webhooks, roles, access, audit evidence, limits, validation, and controlled work management.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before create or change records, formulas, automations or approvals, share sheets, import or export data, connect systems, call APIs, spend funds, or represent status, resource capacity, dependency, approval, delivery date, or completion without evidenced authority, validation, and explicit confirmation.
