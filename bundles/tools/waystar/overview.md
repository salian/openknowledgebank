# Waystar Overview

## Scope

- Financial-clearance, eligibility, authorization, claim, attachment, remittance, denial, payment, and patient-financial workflows supported by the contracted modules.
- Tenant and trading-partner discovery, role and permission review, API and EDI mapping, PHI and payment-data controls, testing, reconciliation, rollback, and release evidence.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect tenant contract edition and enabled modules, payer provider and trading-partner identifiers, users roles and permissions, eligibility authorization claim attachment remittance payment and denial records, API EDI and interface mappings, PHI PCI privacy security and audit controls, test reconciliation rollback approval and release evidence.

## Boundary

Stop before access a tenant, submit eligibility authorization claim attachment or payment transactions, alter records mappings roles or workflows, handle PHI or payment data, connect systems, reconcile money, or represent payer acceptance payment compliance or approval without evidenced authority, validation, and explicit confirmation.
