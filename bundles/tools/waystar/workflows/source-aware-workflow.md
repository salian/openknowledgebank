# Source-Aware Workflow

1. Record objective, account or project scope, date, constraints, and authorized owner.
2. Verify current official sources, edition, region, API or feature version, and lifecycle status.
3. Inspect tenant contract edition and enabled modules, payer provider and trading-partner identifiers, users roles and permissions, eligibility authorization claim attachment remittance payment and denial records, API EDI and interface mappings, PHI PCI privacy security and audit controls, test reconciliation rollback approval and release evidence.
4. Separate `Verified`, `Provided`, `Assumed`, and `Needs verification`.
5. Reconcile conflicts among documentation, configuration, permissions, data, integrations, and logs.
6. Draft the Waystar workflow, integration, validation, reconciliation, and release brief with options, dependencies, privacy and security risks, validation, rollback, and stop conditions.
7. Require explicit confirmation before access a tenant, submit eligibility authorization claim attachment or payment transactions, alter records mappings roles or workflows, handle PHI or payment data, connect systems, reconcile money, or represent payer acceptance payment compliance or approval.
