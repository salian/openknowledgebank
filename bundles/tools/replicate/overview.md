# Replicate Overview

## Scope

- Public and private models, model versions, schema-backed inputs and outputs, synchronous and asynchronous predictions, streaming where supported, files, webhooks, and API clients.
- Deployments, dedicated or autoscaled hardware, training and fine-tuning surfaces where supported, model creation and pushing, tokens, logs, cancellation, data handling, retention, billing, evaluation, and controlled publication.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before upload confidential or protected data, run public or private models, train or deploy models, expose tokens, activate webhooks, spend compute funds, publish outputs, or represent model identity, privacy, accuracy, safety, performance, or cost without evidenced authority, validation, and explicit confirmation.
