# Source-Aware Workflow

1. Record objective, account or project scope, date, constraints, and authorized owner.
2. Verify current official sources, edition, region, API or feature version, and lifecycle status.
3. Inspect contracted capabilities, environment, channels, customer identities and consent, knowledge sources and rights, system instructions, workflows and tools, action scopes, integrations, escalation policy, safety controls, evaluations, monitoring, conversations, and audit logs.
4. Separate `Verified`, `Provided`, `Assumed`, and `Needs verification`.
5. Reconcile conflicts among documentation, configuration, permissions, data, integrations, and logs.
6. Draft the Decagon configuration and use review brief with options, dependencies, privacy and security risks, validation, rollback, and stop conditions.
7. Require explicit confirmation before ingest customer data, deploy AI agents, send messages, call tools or APIs, change accounts or orders, issue refunds or credits, expose knowledge, or represent resolution.
