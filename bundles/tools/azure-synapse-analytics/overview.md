# Azure Synapse Analytics Overview

## Scope

- Integrated data warehousing, big-data processing, data integration, and analytics.
- Workspaces, SQL and Spark pools, pipelines, notebooks, security, monitoring, and Azure integrations.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect Azure subscription, tenant and region, workspace, network boundaries, identities and RBAC, linked services, credentials references, data classifications, SQL and Spark pools, pipelines, notebooks, costs, policies, logs, and recovery state.

## Boundary

Stop before provision or resize resources, connect data sources, execute queries or pipelines, change networking or access, expose secrets or data, delete resources, or represent analytics as validated without evidenced authority, validation, and explicit confirmation.
