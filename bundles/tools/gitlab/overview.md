# GitLab Overview

Use this bundle to reason from current source material and inspected local evidence. It does not prove local state, authorization, outcomes, or compliance.

## Scope

- project, repository, merge request, CI/CD, environment, issue, milestone, permission, security, and audit review

## Key Limitation

- Do not infer branch or merge-request state, pipeline result, deployment status, issue state, permission, vulnerability status, or release outcome.
