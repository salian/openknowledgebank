# Metabase Overview

## Scope

- Visual and SQL questions, models, metrics, collections, dashboards, filters, drill-through, subscriptions, alerts, exports, and usage analytics.
- Databases, metadata, permissions, row and column security, embedding, SSO, API, serialization, Cloud and self-hosted deployment, upgrades, backups, and auditing.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before connect production databases, run queries, expose or export data, publish embeds, change metadata, models, metrics or permissions, deploy upgrades, restore backups, or represent metric, query, security, or availability state without evidenced authority, validation, and explicit confirmation.
