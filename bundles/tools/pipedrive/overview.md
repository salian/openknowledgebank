# Pipedrive Overview

## Scope

- Leads, people, organizations, deals, pipelines, activities, email synchronization, products, quotes and documents, projects, automations, campaigns where licensed, Insights reports, forecasts, and mobile.
- API v2 and supported v1 surfaces, webhooks v2, OpenAPI specifications, marketplace integrations, native MCP, Nova AI features where available, permissions, audit logs, imports, exports, evidence, and controlled updates.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before import or identify contacts, send or track email, create or change leads, deals, activities, projects, products or forecasts, activate automations, grant API or MCP access, enable AI notetaking, or represent pipeline, forecast, meeting, or revenue without evidenced authority, validation, and explicit confirmation.
