# WordPress Overview

Use this bundle to prepare source-aware website content and platform administration analysis and a reviewable wordpress site and change brief.

## Operating Principle

Start with the decision and evidence, not a presumed answer. Use current official or primary sources for general concepts and user-provided or authorized artifacts for local facts. Keep missing evidence visible, reconcile conflicts, and stop before consequential action without accountable approval.

## Scope

- General context: use the sources listed in the bundle metadata.
- Local conclusions: require current artifacts covering hosting, WordPress version, site, and network scope, roles and capabilities, themes, plugins, and versions, content, media, comments, and publication state, settings and permalinks, and backups, staging, security, cache, and SEO configuration.
- Unknowns: do not infer production state, plugin compatibility, role capability, content status, backup recoverability, and cache behavior.
- Action boundary: require confirmation before publishing or deleting content, installing or updating themes, plugins, or core, changing users or roles, or changing production configuration.
