# Source-Aware Workflow

1. Record objective, account or project scope, date, constraints, and authorized owner.
2. Verify current official sources, edition, region, API or feature version, and lifecycle status.
3. Inspect deployment model and version, account, inboxes and channels, contacts and identity validation, conversations, consent and retention, agents and permissions, automations, knowledge content, AI configuration, API scopes, integrations, hosting and backups, and logs.
4. Separate `Verified`, `Provided`, `Assumed`, and `Needs verification`.
5. Reconcile conflicts among documentation, configuration, permissions, data, integrations, and logs.
6. Draft the Chatwoot configuration and use review brief with options, dependencies, privacy and security risks, validation, rollback, and stop conditions.
7. Require explicit confirmation before connect channels, import contacts, send or automate messages, expose conversation history, publish help content, enable AI responses, change permissions, deploy upgrades, or represent resolution.
