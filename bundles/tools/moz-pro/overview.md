# Moz Pro Overview

## Scope

- Campaigns, keyword research, rank tracking, search visibility, site crawl and technical issues, on-page optimization, competitive research, link metrics, and custom reports.
- Search landscape and feature tracking, locations and engines, Moz metrics, exports, integrations and APIs where applicable, evidence history, validation, and controlled recommendations.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before create campaigns, crawl sites, track competitors or locations, change SEO recommendations, export data, use API quotas, publish claims, or represent rank, traffic, authority, issue severity, causality, or business impact without evidenced authority, validation, and explicit confirmation.
