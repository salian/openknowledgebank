# Omni Analytics Overview

## Scope

- Semantic models, dimensions, measures, relationships, topics, workbooks, point-and-click and SQL queries, spreadsheet formulas, visualizations, dashboards, schedules, and embedding.
- Conversational and workbook agents, Modeling Agent, MCP and APIs, skills, Git and branch workflows, dbt integration, row and column permissions, SSO, content validation, usage analysis, and governed data products.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before connect warehouses, run or schedule queries, expose or embed data, change semantic models or metrics, merge branches, grant permissions, enable agents or MCP, send data to model providers, or represent query, metric, AI, security, or business results without evidenced authority, validation, and explicit confirmation.
