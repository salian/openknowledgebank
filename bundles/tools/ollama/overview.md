# Ollama Overview

## Scope

- Model pull, run, create, copy, list and delete operations, Modelfiles, chat and generate APIs, streaming, structured outputs, tool calling, embeddings, and vision where model-supported.
- Local and cloud models, authentication where required, OpenAI-compatible endpoints where documented, Python and JavaScript libraries, context and runtime settings, GPU use, logs, deployment, security, validation, and resource controls.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before download or execute models, send data to cloud models, expose API endpoints, run model-requested tools, alter model files, delete models, consume GPU, memory or paid resources, or represent model identity, privacy, output accuracy, tool execution, or safety without evidenced authority, validation, and explicit confirmation.
