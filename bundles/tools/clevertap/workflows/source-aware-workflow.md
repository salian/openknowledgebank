# Source-Aware Workflow

1. Record objective, account or project scope, date, constraints, and authorized owner.
2. Verify current official sources, edition, region, API or feature version, and lifecycle status.
3. Inspect account, region and API version, credentials, user identifiers, profile and event schemas, consent and suppression, identity rules, segments and cohorts, campaigns and journeys, templates and channels, experiments, recommendations, catalogs, integrations, reports, and logs.
4. Separate `Verified`, `Provided`, `Assumed`, and `Needs verification`.
5. Reconcile conflicts among documentation, configuration, permissions, data, integrations, and logs.
6. Draft the CleverTap configuration and use review brief with options, dependencies, privacy and security risks, validation, rollback, and stop conditions.
7. Require explicit confirmation before ingest or export user data, merge identities, change consent, activate segments, campaigns or journeys, send messages, run experiments, use credentials, or represent engagement outcomes.
