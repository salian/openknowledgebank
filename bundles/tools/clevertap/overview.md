# CleverTap Overview

## Scope

- Customer profiles, events, segments, journeys, campaigns, recommendations, experimentation, and analytics.
- APIs, SDKs, identity, consent, messaging channels, webhooks, catalogs, integrations, and reporting.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect account, region and API version, credentials, user identifiers, profile and event schemas, consent and suppression, identity rules, segments and cohorts, campaigns and journeys, templates and channels, experiments, recommendations, catalogs, integrations, reports, and logs.

## Boundary

Stop before ingest or export user data, merge identities, change consent, activate segments, campaigns or journeys, send messages, run experiments, use credentials, or represent engagement outcomes without evidenced authority, validation, and explicit confirmation.
