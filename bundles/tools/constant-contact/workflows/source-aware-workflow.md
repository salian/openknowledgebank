# Source-Aware Workflow

1. Record objective, account or project scope, date, constraints, and authorized owner.
2. Verify current official sources, edition, region, API or feature version, and lifecycle status.
3. Inspect account and API version, OAuth scopes, contacts and provenance, consent and suppression, lists and segments, sender and domain authentication, content and templates, campaigns and automations, schedules, events, webhooks, reports, attribution, and logs.
4. Separate `Verified`, `Provided`, `Assumed`, and `Needs verification`.
5. Reconcile conflicts among documentation, configuration, permissions, data, integrations, and logs.
6. Draft the Constant Contact configuration and use review brief with options, dependencies, privacy and security risks, validation, rollback, and stop conditions.
7. Require explicit confirmation before import or update contacts, change consent or suppression, authenticate senders, create, schedule or send campaigns, activate automation, use OAuth, or represent delivery or conversion.
