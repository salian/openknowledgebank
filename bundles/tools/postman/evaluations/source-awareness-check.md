# Postman source-awareness check

Check that responses:

- answer directly using the required visible sections
- name official source categories and local evidence
- separate verified, provided, assumed, and missing information
- avoid inventing endpoint behavior, schemas, variables, credentials, tests, responses, environment, monitor state
- define verification steps for conflicts and source-of-record checks
- require confirmation before sending state-changing requests, exposing credentials, changing collections or environments, running monitors, exporting data, or publishing APIs
