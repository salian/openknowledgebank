# Penpot Overview

## Scope

- Vector design, boards, components, variants, libraries, design tokens, flex and grid layouts, typography, assets, prototyping, interactions, comments, collaboration, version history, and exports.
- Inspect mode and CSS/code handoff, plugins and APIs where documented, workspaces, projects, teams, permissions, cloud and self-hosted deployment, backups, upgrades, evidence, and validation.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before upload protected assets, edit shared designs or libraries, publish prototypes, run plugins, expose tokens, change team access, export production assets, deploy or upgrade servers, or represent design fidelity, accessibility, code quality, rights, or availability without evidenced authority, validation, and explicit confirmation.
