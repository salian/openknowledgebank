# Drupal Overview

## Scope

- Content modeling, authoring, publishing, media, taxonomy, workflows, multilingual sites, and web application development.
- Core and contributed modules, themes, users, permissions, configuration, APIs, updates, caching, deployment, and security operations.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect Drupal core version, hosting and PHP stack, site and environment, modules and themes with versions and provenance, content types and workflows, users and permissions, media rights, configuration, custom code, integrations, caching, backups, security advisories, tests, and rollback state.

## Boundary

Stop before install or update code, modules or themes, change schemas, content, workflows or permissions, run database updates, publish or delete content, deploy configuration, or represent security or compatibility without evidenced authority, validation, and explicit confirmation.
