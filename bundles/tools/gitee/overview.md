# Gitee Overview

## Scope

- Git repository hosting, code history, branches, forks, issues, pull requests, collaboration, and downloads.
- Organizations, access, integrations, configuration, audit evidence, validation, and controlled software delivery.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect account and edition, repositories and code, branches, organizations, users and permissions, reviews, integrations, workflows, logs, licensing, tests, rollback, and approvals.

## Boundary

Stop before create or delete repositories, push or merge code, change access, run delivery workflows, publish artifacts, migrate data, or represent review, security, or deployment state without evidenced authority, validation, and explicit confirmation.
