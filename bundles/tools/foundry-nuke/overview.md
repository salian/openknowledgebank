# Foundry Nuke Overview

## Scope

- Node-based compositing, keying, roto, paint, tracking, 3D compositing, deep workflows, color management, image and video formats, and rendering.
- NukeX tools, Nuke Studio editorial and conform, Hiero review, Python and APIs, gizmos and plugins, collaboration, pipeline integration, versions, licenses, validation, and delivery.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before overwrite source or render files, run scripts or plugins, change color management, conform timelines, submit render jobs, share protected media, alter pipeline state, consume licenses, or represent image integrity, delivery, or rights without evidenced authority, validation, and explicit confirmation.
