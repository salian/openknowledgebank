# Source-Aware Workflow

1. Record objective, account or project scope, date, constraints, and authorized owner.
2. Verify current official sources, edition, region, API or feature version, and lifecycle status.
3. Inspect contract and product version, report suites, datastreams, variables, processing rules, identities, consent, segments, metrics, attribution settings, exports, and logs.
4. Separate `Verified`, `Provided`, `Assumed`, and `Needs verification`.
5. Reconcile conflicts among documentation, configuration, permissions, data, integrations, and logs.
6. Draft the Adobe Analytics configuration and use review brief with options, dependencies, privacy and security risks, validation, rollback, and stop conditions.
7. Require explicit confirmation before change data collection or processing, publish segments, export person-level data, alter attribution, deploy tags, or represent findings as validated.
