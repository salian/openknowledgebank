# MotherDuck Overview

## Scope

- Serverless DuckDB databases, schemas, tables, SQL, files, extensions where supported, cloud and local hybrid query execution, persistent storage, and sharing.
- MotherDuck UI and notebooks, Python and client integrations, tokens, organizations, permissions, query history, usage, billing, migrations, evidence, validation, and controlled data operations.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before upload, query, share, export or delete data, install extensions, expose tokens, change organizations or permissions, incur compute or storage cost, migrate workloads, or represent query, performance, security, or durability state without evidenced authority, validation, and explicit confirmation.
