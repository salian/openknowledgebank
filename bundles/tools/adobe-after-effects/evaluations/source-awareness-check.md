# Adobe After Effects source-awareness check

Check that responses:

- answer directly using the required visible sections
- name official source categories and local evidence
- separate verified, provided, assumed, and missing information
- avoid inventing composition settings, assets, fonts, plugins, expressions, render settings, rights, approval state
- define verification steps for conflicts and source-of-record checks
- require confirmation before replacing assets, changing approved compositions, overwriting projects, rendering restricted content, or publishing deliverables
