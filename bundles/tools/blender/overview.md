# Blender Overview

## Scope

- 3D modeling, sculpting, animation, rigging, simulation, rendering, compositing, video editing, and scripting.
- Scenes, assets, add-ons, Python automation, formats, color management, render engines, and production pipelines.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect installed Blender version and build, scene and linked assets, licenses and rights, add-ons and scripts, render engine and devices, simulation caches, color management, output settings, file paths, render tests, and quality-control results.

## Boundary

Stop before run untrusted scripts or add-ons, modify or overwrite production files, bake simulations, render at material cost, export assets, publish work, or represent rights or quality approval without evidenced authority, validation, and explicit confirmation.
