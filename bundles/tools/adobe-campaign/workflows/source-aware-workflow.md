# Source-Aware Workflow

1. Record objective, account or project scope, date, constraints, and authorized owner.
2. Verify current official sources, edition, region, API or feature version, and lifecycle status.
3. Inspect product generation and build, instance, profiles, schemas, consent, typologies, workflows, templates, deliveries, integrations, permissions, and logs.
4. Separate `Verified`, `Provided`, `Assumed`, and `Needs verification`.
5. Reconcile conflicts among documentation, configuration, permissions, data, integrations, and logs.
6. Draft the Adobe Campaign configuration and use review brief with options, dependencies, privacy and security risks, validation, rollback, and stop conditions.
7. Require explicit confirmation before import profiles, activate workflows, send communications, change personalization or suppression, deploy schemas, or represent consent or delivery.
