# OpenTofu Overview

## Scope

- Declarative configuration, providers, resources, data sources, modules, variables, outputs, functions, dependency graphs, planning, applying, importing, testing, and workspaces.
- Local and remote state backends, state and plan encryption, locking, provider and module registries, CLI automation, migration, version constraints, credentials, policy controls, validation, and rollback planning.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before initialize providers, read or modify state, plan or apply infrastructure, import or destroy resources, rotate encryption metadata, expose credentials, change backends, run provisioners, or represent infrastructure, drift, security, or availability without evidenced authority, validation, and explicit confirmation.
