# Hex Overview

## Scope

- Collaborative SQL, Python and R notebooks, no-code cells, data connections, charts, maps, tables, reactive execution, apps, reports, and schedules.
- Notebook Agent, semantic models, Threads, MCP, CLI, permissions, secrets, versioning, evidence, and validation.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect workspace and plan, projects and versions, connections and schemas, queries and code, packages and secrets, semantic models and metrics, parameters, schedules and apps, permissions, AI interactions, outputs, logs, lineage, validation, and approvals.

## Boundary

Stop before connect or expose data, run code or queries, install packages, use secrets, change metrics, publish apps, schedule jobs, enable AI or MCP, make consequential decisions, or represent analytical results without evidenced authority, validation, and explicit confirmation.
