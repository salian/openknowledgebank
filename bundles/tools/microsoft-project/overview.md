# Microsoft Project Overview

Use this bundle to prepare source-aware Microsoft Project schedule, dependency, resource, baseline, and variance review and a review-ready Microsoft Project schedule brief.

## Operating Principle

Start with the decision and evidence, not a presumed answer. Use current authoritative sources for general behavior and authorized artifacts for local facts. Keep missing evidence visible, reconcile conflicts, and stop before consequential action without accountable approval.

## Scope

- Required evidence: Project product, edition, version, file, owner, status date, calendar, work breakdown, tasks, milestones, durations, dependencies, constraints, deadlines, resources, rates, assignments, availability, costs, baseline identity and date, actuals, progress method, critical-path settings, external links, reports, and approvals.
- Unknowns: do not infer finish date, critical path, resource availability, variance, cost, progress, baseline meaning, or schedule feasibility.
- Action boundary: require confirmation before actions that overwrite the schedule, set or clear a baseline, change assignments or calendars, publish the plan, notify resources, or commit dates or costs.
