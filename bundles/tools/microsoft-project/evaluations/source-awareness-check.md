# Microsoft Project Source-Awareness Check

Check that responses answer directly, preserve prompt facts, name applicable authoritative URLs, separate evidence states, avoid inventing finish date, critical path, resource availability, variance, cost, progress, baseline meaning, or schedule feasibility, leave unevidenced reviewers and provenance as `Needs verification`, define conflict checks, and require confirmation before actions that overwrite the schedule, set or clear a baseline, change assignments or calendars, publish the plan, notify resources, or commit dates or costs.
