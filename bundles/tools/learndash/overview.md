# LearnDash Overview

## Scope

- Course builder, lessons, topics, quizzes, questions, assignments, essays, certificates, access, progression, users, groups, leaders, and reporting.
- WordPress roles, add-ons, payments, SCORM and xAPI, REST API, MCP-based user and group automation, exports, evidence, validation, and controlled learning administration.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before publish courses, create or change enrollments, extend access, grade assignments or essays, change progress, scores or certificates, send group email, export learner data, run MCP actions, or represent completion without evidenced authority, validation, and explicit confirmation.
