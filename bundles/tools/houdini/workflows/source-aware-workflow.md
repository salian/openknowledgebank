# Source-Aware Workflow

1. Record objective, account or project scope, date, constraints, and authorized owner.
2. Verify current official sources, edition, region, API or feature version, and lifecycle status.
3. Inspect version and edition, project and scene, node graphs and parameters, assets and rights, geometry and caches, simulations, materials and lighting, renderer and color settings, plug-ins and dependencies, licenses, farm and resources, outputs, logs, tests, rollback, and approvals.
4. Separate `Verified`, `Provided`, `Assumed`, and `Needs verification`.
5. Reconcile conflicts among documentation, configuration, permissions, data, integrations, and logs.
6. Draft the Houdini procedural production and render review brief with options, dependencies, privacy and security risks, validation, rollback, and stop conditions.
7. Require explicit confirmation before modify production scenes or assets, run simulations or renders, distribute jobs, install plug-ins, consume licenses or compute, publish media, overwrite outputs, or represent quality or delivery.
