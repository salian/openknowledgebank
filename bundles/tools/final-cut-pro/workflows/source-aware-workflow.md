# Source-Aware Workflow

1. Record objective, account or project scope, date, constraints, and authorized owner.
2. Verify current official sources, edition, region, API or feature version, and lifecycle status.
3. Inspect current product identity and lifecycle, account or deployment, edition and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.
4. Separate `Verified`, `Provided`, `Assumed`, and `Needs verification`.
5. Reconcile conflicts among documentation, configuration, permissions, data, integrations, and logs.
6. Draft the Final Cut Pro configuration and use review brief with options, dependencies, privacy and security risks, validation, rollback, and stop conditions.
7. Require explicit confirmation before import or relink media, edit timelines, generate captions, isolate subjects, grade color, use plugins, export masters, publish, or represent rights or technical compliance.
