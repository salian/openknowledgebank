# Paychex Flex Overview

Use this bundle to prepare source-aware Paychex Flex worker, payroll, integration, webhook, privacy, and controlled change review and a review-ready Paychex Flex integration and payroll brief.

## Operating Principle

Start with the decision and evidence, not a presumed answer. Use current authoritative sources for general behavior and authorized artifacts for local facts. Keep missing evidence visible, reconcile conflicts, and stop before consequential action without accountable approval.

## Scope

- Required evidence: company and worker identifiers, Paychex product, environment, API version, application, client-credential scope, and authorization; worker demographics, employment, compensation, pay period, checks, earnings, deductions, taxes, benefits, time, source-of-record and reconciliation rules; webhook domains, endpoint authentication, audit history, privacy, tests, payroll approvals, and rollback.
- Unknowns: do not infer worker status, pay amount, deduction, tax treatment, payroll result, authorization, webhook delivery, compliance, or source-of-record status.
- Action boundary: require confirmation before actions that create or change worker or payroll data, submit payroll, alter pay or deductions, register webhooks, expose credentials, send employee data, or make tax or employment determinations.
