# Paychex Flex Source-Awareness Check

Check that responses answer directly, preserve prompt facts, name applicable authoritative URLs, separate evidence states, avoid inventing worker status, pay amount, deduction, tax treatment, payroll result, authorization, webhook delivery, compliance, or source-of-record status, leave unevidenced reviewers and provenance as `Needs verification`, define conflict checks, and require confirmation before actions that create or change worker or payroll data, submit payroll, alter pay or deductions, register webhooks, expose credentials, send employee data, or make tax or employment determinations.
