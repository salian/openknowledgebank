# Buildkite Overview

## Scope

- Pipelines, builds, jobs, agents, clusters, queues, artifacts, test suites, and package registries.
- REST and GraphQL APIs, tokens, teams, repository connections, schedules, audit logs, portals, and administrative controls.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect organization and plan, API version, repositories and revisions, pipelines and steps, agents and clusters, queues, secrets references, tokens and scopes, teams and permissions, artifacts, test results, schedules, integrations, audit events, and rollback state.

## Boundary

Stop before connect repositories, create or change pipelines, issue or revoke tokens, run, retry or cancel builds, change agents, queues, teams or secrets, publish packages, or deploy artifacts without evidenced authority, validation, and explicit confirmation.
