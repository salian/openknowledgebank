# ONLYOFFICE Overview

## Scope

- Browser and desktop editors for text documents, spreadsheets, presentations, PDFs, forms and diagrams, co-editing, comments, review, versioning, conversion, and collaboration.
- Cloud and self-hosted editions, JWT and IP filtering, connectors, Docs API, Office API, Document Builder, plugins, macros, AI-provider integration, updates, backups, and security configuration.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before upload or share protected documents, edit or convert originals, run plugins, macros or builder scripts, connect AI providers, expose JWT secrets, change access, deploy updates, or represent document integrity, rights, signature, or security without evidenced authority, validation, and explicit confirmation.
