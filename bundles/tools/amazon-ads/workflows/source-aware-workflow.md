# Source-Aware Workflow

1. Record objective, account or project scope, date, constraints, and authorized owner.
2. Verify current official sources, edition, region, API or feature version, and lifecycle status.
3. Inspect advertiser and marketplace, account permissions, API version, profiles, campaigns, targeting, budgets, creatives, product data, attribution settings, and logs.
4. Separate `Verified`, `Provided`, `Assumed`, and `Needs verification`.
5. Reconcile conflicts among documentation, configuration, permissions, data, integrations, and logs.
6. Draft the Amazon Ads configuration and use review brief with options, dependencies, privacy and security risks, validation, rollback, and stop conditions.
7. Require explicit confirmation before create or modify campaigns, change bids or budgets, upload audiences or creatives, use credentials, launch ads, or represent performance as validated.
