# Pulumi Overview

## Scope

- Infrastructure definitions in supported programming languages and YAML, providers, resources, components, stacks, configuration, outputs, previews, updates, imports, refresh, destroy, and state management.
- Pulumi Cloud and self-managed backend scope, Deployments, Automation API, ESC environments and secrets, policy as code, templates, packages, identity and access, audit logs, drift, costs, AI assistance, validation, and rollback.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before read or modify state, preview or deploy infrastructure, import or destroy resources, expose secrets, change environments or policies, run automation, enable cloud deployments or AI, or represent infrastructure, drift, security, cost, or availability without evidenced authority, validation, and explicit confirmation.
