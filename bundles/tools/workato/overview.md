# Workato Overview

## Scope

- Recipes, triggers, actions, conditions, loops, data mapping, connections, jobs, schedules, error handling, callable recipes, connectors, on-prem agents and workspace collaboration.
- API platform, event and data orchestration, agentic and AI capabilities where available, custom connectors, environments and deployment, roles, secrets and keys, audit and usage evidence, testing, rollback, and controlled automation.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before connect production systems, expose credentials, read or change records, publish APIs, run recipes or agents, move sensitive data, enable AI, spend funds, or represent trigger, job, transaction, API, data quality, approval, or business completion without evidenced authority, validation, and explicit confirmation.
