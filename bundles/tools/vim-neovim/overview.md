# Vim and Neovim Overview

Source-aware guidance for Vim and Neovim configuration, plugins, automation, file safety, security, and controlled change.

## Evidence Contract

Relevant evidence includes exact product, version, runtime paths, configuration files, plugin manager, plugins, lockfiles, commands, mappings, autocommands, external tools, target files, backups, tests, owners, and approvals. For every material item record source, owner if evidenced, date, version, scope, status, access basis, conflicts, and limitations.

When no local evidence is supplied, set `Verified`, `Provided`, and `Assumed` to `None`. Put exact missing artifacts under `Needs verification`. A general disclaimer is not a substitute for requesting evidence.

## Boundary

Analysis and drafting do not establish Product identity, version behavior, runtime state, plugin provenance, command effects, file contents, backup status, compatibility, and authority. Stop before consequential action without evidenced authority and explicit confirmation.
