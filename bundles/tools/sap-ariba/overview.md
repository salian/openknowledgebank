# SAP Ariba Overview

Use this bundle to prepare source-aware SAP Ariba procurement configuration, approval, integration, and transaction review and a review-ready SAP Ariba change and approval brief.

## Operating Principle

Start with the decision and evidence, not a presumed answer. Use current authoritative sources for general behavior and authorized artifacts for local facts. Keep missing evidence visible, reconcile conflicts, and stop before consequential action without accountable approval.

## Scope

- Required evidence: tenant, enabled SAP Ariba products, release, realm, and environment; user, group, role, permission, supplier, catalog, accounting, and master-data scope; approvable type, document, lines, amounts, rules, approval flow, delegation, contracts, integration mappings, ERP source, audit history, tests, and approvals.
- Unknowns: do not infer approval path, document status, supplier state, budget availability, accounting validity, integration result, compliance, or transaction outcome.
- Action boundary: require confirmation before actions that change configuration or master data, approve or deny, submit a requisition or invoice, create an order, onboard a supplier, export data, or commit spend.
