# OBS Studio Overview

## Scope

- Scenes, sources, display and window capture, cameras, media, browser sources, transitions, filters, audio mixing, monitoring, recording, replay buffer, and streaming.
- Profiles, scene collections, encoders, output formats, multitrack audio, virtual camera, hotkeys, Studio Mode, plugins, WebSocket automation, logs, performance, and recovery.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before capture screens, cameras or microphones, expose private windows or credentials, start broadcasts or recordings, overwrite media, install plugins, run automation, change stream keys, or represent consent, delivery, recording integrity, or availability without evidenced authority, validation, and explicit confirmation.
