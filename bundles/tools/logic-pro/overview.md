# Logic Pro Overview

## Scope

- Audio and MIDI recording, comping, editing, arranging, Live Loops, beat making, sampling, instruments, effects, Session Players, Stem Splitter, and project exchange.
- Mixing, automation, Mastering Assistant, Dolby Atmos Spatial Audio, ADM and audio export, plug-ins, sound libraries, rights, technical validation, and controlled release.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before record people, import protected media, install plug-ins, separate stems, use AI-assisted performers or mastering, overwrite projects, export masters, publish music, or represent rights, mix quality, or release readiness without evidenced authority, validation, and explicit confirmation.
