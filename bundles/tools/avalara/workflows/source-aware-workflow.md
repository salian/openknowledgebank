# Source-Aware Workflow

1. Record objective, account or project scope, date, constraints, and authorized owner.
2. Verify current official sources, edition, region, API or feature version, and lifecycle status.
3. Inspect product and API version, account and company, jurisdictions, registrations and nexus, tax codes, addresses, customers, exemptions, transaction and document state, filing settings, credentials, integrations, and logs.
4. Separate `Verified`, `Provided`, `Assumed`, and `Needs verification`.
5. Reconcile conflicts among documentation, configuration, permissions, data, integrations, and logs.
6. Draft the Avalara configuration and use review brief with options, dependencies, privacy and security risks, validation, rollback, and stop conditions.
7. Require explicit confirmation before calculate or commit tax, create or adjust transactions, validate addresses, change nexus or filing configuration, submit returns, handle exemptions, or represent tax liability.
