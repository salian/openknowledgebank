# n8n Overview

## Scope

- Trigger and action nodes, data transformation, expressions, branching, loops, sub-workflows, error handling, schedules, webhooks, forms, executions, and templates.
- Credentials, projects, roles, source control and environments where supported, public API, custom nodes, code, AI agents and tools, human fallback, Cloud and self-hosted deployment, scaling, and security.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before store credentials, call external or production systems, execute code or AI tools, activate schedules or webhooks, process personal data, install community nodes, change access, deploy or upgrade instances, or represent execution, delivery, security, or business results without evidenced authority, validation, and explicit confirmation.
