# TYPO3 Overview

## Scope

- Sites and page trees, content elements, assets, localization, workspaces and publishing workflows, forms, search and other configured CMS capabilities, backend users and permissions.
- TypoScript and site configuration, Fluid templates, extensions and Composer packages, APIs and integrations, supported LTS lifecycle, hosting and deployment, upgrades, security advisories, backup, validation, rollback, and controlled publication.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before change site configuration or content, publish pages, install extensions, execute upgrades, grant access, expose credentials, deploy code, or represent version support, content state, extension safety, migration, accessibility, security, or publication without evidenced authority, validation, and explicit confirmation.
