# Source-Aware Workflow

1. Record objective, account or project scope, date, constraints, and authorized owner.
2. Verify current official sources, edition, region, API or feature version, and lifecycle status.
3. Inspect subscription and region, people and company records, data provenance, lawful basis, suppression and consent, sequences, mailboxes, CRM mappings, API scopes, credits, and logs.
4. Separate `Verified`, `Provided`, `Assumed`, and `Needs verification`.
5. Reconcile conflicts among documentation, configuration, permissions, data, integrations, and logs.
6. Draft the Apollo.io configuration and use review brief with options, dependencies, privacy and security risks, validation, rollback, and stop conditions.
7. Require explicit confirmation before search for or enrich people, export personal data, enroll contacts, send messages, place calls, update CRM records, connect mailboxes, or represent consent or intent.
