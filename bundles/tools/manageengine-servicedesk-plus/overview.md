# ManageEngine ServiceDesk Plus Overview

## Scope

- Requests, incidents, problems, changes, releases, projects, service catalogs, knowledge, SLAs, automation, reports, and dashboards.
- Assets, purchases, contracts, CMDB, cloud and on-premises editions, integrations, REST API v3, scripts, roles, audit evidence, and controlled IT operations.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before create or alter tickets, assets, contracts, changes or releases, run scripts, change workflows or permissions, expose OAuth credentials, call production APIs, or represent SLA, change, asset, or service state without evidenced authority, validation, and explicit confirmation.
