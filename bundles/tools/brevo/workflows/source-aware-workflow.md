# Source-Aware Workflow

1. Record objective, account or project scope, date, constraints, and authorized owner.
2. Verify current official sources, edition, region, API or feature version, and lifecycle status.
3. Inspect account and region, plan and API version, credentials, contacts and attributes, lawful basis, consent and suppression, lists and segments, senders and domains, templates, campaigns and automations, transactional events, webhooks, integrations, reports, and logs.
4. Separate `Verified`, `Provided`, `Assumed`, and `Needs verification`.
5. Reconcile conflicts among documentation, configuration, permissions, data, integrations, and logs.
6. Draft the Brevo configuration and use review brief with options, dependencies, privacy and security risks, validation, rollback, and stop conditions.
7. Require explicit confirmation before import or update contacts, change consent or suppression, authenticate domains, send messages, activate campaigns or automations, use credentials, update CRM records, or represent delivery.
