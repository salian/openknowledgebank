# LibreOffice Overview

Source-aware guidance for LibreOffice document production, compatibility, automation, accessibility, metadata, and controlled export.

## Evidence Contract

Relevant evidence includes application version, module, source files, formats, templates, styles, fonts, macros, extensions, data sources, accessibility criteria, metadata, export settings, and approvals. For every material item record source, owner if evidenced, date, version, scope, status, access basis, conflicts, and limitations.

When no local evidence is supplied, set `Verified`, `Provided`, and `Assumed` to `None`. Put exact missing artifacts under `Needs verification`. A general disclaimer is not a substitute for requesting evidence.

## Boundary

Analysis and drafting do not establish Document contents, compatibility, macro safety, formatting fidelity, accessibility, metadata state, and export fidelity. Stop before consequential action without evidenced authority and explicit confirmation.
