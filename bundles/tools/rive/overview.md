# Rive Overview

## Scope

- Vector design, shapes, paths, text, images, bones, constraints, keys, timelines, interpolation, animation mixing, state machines, inputs, listeners, events, and data binding.
- Editor and runtime version distinctions, web, mobile, game and framework runtimes, .riv files, runtime APIs, layout and fit, rendering, caching, performance, accessibility, collaboration, asset rights, validation, and controlled release.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before upload protected assets, alter shared files, publish interactive media, embed runtimes, trigger application actions from events, update dependencies, export production assets, or represent rights, behavior, performance, accessibility, or compatibility without evidenced authority, validation, and explicit confirmation.
