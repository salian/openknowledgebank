# Adobe Experience Manager Overview

## Scope

- Web content and digital asset management.
- Sites, assets, forms, workflows, cloud environments, publication, and integrations.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect deployment model and version, repositories, sites, assets, metadata, workflows, permissions, environments, integrations, publishing state, and logs.

## Boundary

Stop before edit or publish content, change workflows or permissions, deploy code, move assets, collect form data, or represent release approval without evidenced authority, validation, and explicit confirmation.
