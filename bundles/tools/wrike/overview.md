# Wrike Overview

## Scope

- Spaces, folders, projects, tasks and subtasks, custom item types and fields, views, calendars, dependencies, workflows, request forms, proofing, approvals, time tracking and reports.
- Resource management and portfolio features where licensed, automation, integrations, apps, REST API and webhooks, roles and access, audit evidence, limits, validation, rollback, and controlled work management.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before create or alter projects, tasks, dependencies, workflows or approvals, assign people, run automations, share data, expose tokens, call APIs, or represent ownership, effort, resource capacity, status, approval, delivery date, or completion without evidenced authority, validation, and explicit confirmation.
