# Semrush source-awareness check

Check that responses:

- answer directly using the required visible sections
- name official source categories and local evidence
- separate verified, provided, assumed, and missing information
- avoid inventing domain scope, keyword universe, rankings, traffic estimates, competitors, crawl settings, issues, report freshness
- define verification steps for conflicts and source-of-record checks
- require confirmation before changing projects, campaigns, tracking, integrations, exports, billing, or publishing unsupported market claims
