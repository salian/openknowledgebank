# Rocket.Chat Overview

## Scope

- Public and private channels, direct messages, threads, files, search, notifications, voice and video integrations, omnichannel conversations, routing, queues, canned responses, and analytics.
- Cloud and self-managed deployment, federation where supported, apps, bots, webhooks, REST and realtime APIs, authentication, roles, retention, audit, encryption features, upgrades, backups, observability, validation, and recovery.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before send or delete messages, expose files or credentials, initiate calls, change routing, retention or permissions, install apps, run bots, authorize APIs, federate servers, deploy upgrades, or represent delivery, confidentiality, encryption, incident, or compliance state without evidenced authority, validation, and explicit confirmation.
