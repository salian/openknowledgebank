# Source-Aware Workflow

1. Record objective, account or project scope, date, constraints, and authorized owner.
2. Verify current official sources, edition, region, API or feature version, and lifecycle status.
3. Inspect plan and region, REST version, portal, users and structure, CRM records, tasks, chats, files, products and stock, calendars, permissions, webhooks, application scopes, integrations, limits, and logs.
4. Separate `Verified`, `Provided`, `Assumed`, and `Needs verification`.
5. Reconcile conflicts among documentation, configuration, permissions, data, integrations, and logs.
6. Draft the Bitrix24 configuration and use review brief with options, dependencies, privacy and security risks, validation, rollback, and stop conditions.
7. Require explicit confirmation before create or update CRM or workplace records, send messages, change users or permissions, upload files, alter catalog or stock data, install apps, invoke webhooks, or represent completion.
