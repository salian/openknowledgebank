# Visual Studio Code Overview

Use this bundle to prepare source-aware editor workspace and development configuration analysis and a reviewable vs code workspace and configuration brief.

## Operating Principle

Start with the decision and evidence, not a presumed answer. Use current official or primary sources for general concepts and user-provided or authorized artifacts for local facts. Keep missing evidence visible, reconcile conflicts, and stop before consequential action without accountable approval.

## Scope

- General context: use the sources listed in the bundle metadata.
- Local conclusions: require current artifacts covering VS Code version and build, workspace files and folder scope, user, remote, and workspace settings, extensions and versions, Workspace Trust state, and tasks, launch configurations, terminals, language tooling, and logs.
- Unknowns: do not infer effective setting precedence, extension behavior, workspace trust, task execution state, debug configuration, and local file contents.
- Action boundary: require confirmation before opening an untrusted workspace, installing or enabling extensions, changing files or settings, running tasks or terminals, or syncing settings.
