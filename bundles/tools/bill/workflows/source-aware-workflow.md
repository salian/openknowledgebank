# Source-Aware Workflow

1. Record objective, account or project scope, date, constraints, and authorized owner.
2. Verify current official sources, edition, region, API or feature version, and lifecycle status.
3. Inspect current product and API version, organization, users and roles, vendors and customers, bills and invoices, bank and payment methods, approvals, accounting mappings, sync state, fraud controls, credentials, transactions, and logs.
4. Separate `Verified`, `Provided`, `Assumed`, and `Needs verification`.
5. Reconcile conflicts among documentation, configuration, permissions, data, integrations, and logs.
6. Draft the BILL configuration and use review brief with options, dependencies, privacy and security risks, validation, rollback, and stop conditions.
7. Require explicit confirmation before create or approve bills or invoices, add vendors or bank details, initiate or void payments, change roles or workflows, sync accounting records, or represent settlement.
