# Bitbucket Overview

Use this bundle to reason from current source material and inspected local evidence. It does not prove local state, authorization, outcomes, or compliance.

## Scope

- repository, branch, pull request, merge check, pipeline, deployment, permission, and audit review

## Key Limitation

- Do not infer branch or pull-request state, pipeline result, merge eligibility, deployment state, permission, artifact provenance, or release outcome.
