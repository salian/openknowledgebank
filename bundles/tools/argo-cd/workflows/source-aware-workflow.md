# Source-Aware Workflow

1. Record objective, account or project scope, date, constraints, and authorized owner.
2. Verify current official sources, edition, region, API or feature version, and lifecycle status.
3. Inspect Argo CD and Kubernetes versions, repositories and revisions, application specs, clusters, namespaces, projects, RBAC, SSO, secrets references, health, sync policy, hooks, diffs, events, and audit logs.
4. Separate `Verified`, `Provided`, `Assumed`, and `Needs verification`.
5. Reconcile conflicts among documentation, configuration, permissions, data, integrations, and logs.
6. Draft the Argo CD configuration and use review brief with options, dependencies, privacy and security risks, validation, rollback, and stop conditions.
7. Require explicit confirmation before connect repositories or clusters, change manifests or projects, sync or prune applications, rotate credentials, alter RBAC, or represent deployment health.
