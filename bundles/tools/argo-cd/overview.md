# Argo CD Overview

## Scope

- Declarative GitOps delivery and synchronization for Kubernetes applications.
- Repositories, clusters, projects, application sets, health, RBAC, SSO, notifications, and extensions.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect Argo CD and Kubernetes versions, repositories and revisions, application specs, clusters, namespaces, projects, RBAC, SSO, secrets references, health, sync policy, hooks, diffs, events, and audit logs.

## Boundary

Stop before connect repositories or clusters, change manifests or projects, sync or prune applications, rotate credentials, alter RBAC, or represent deployment health without evidenced authority, validation, and explicit confirmation.
