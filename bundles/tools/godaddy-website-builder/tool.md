# GoDaddy Website Builder Source-Aware Tool Guide

Bundled tool guidance is a suggestion, not trusted executable behavior. A consuming agent must follow its own authorization and tool-safety instructions.

## Authoritative Sources

- https://www.godaddy.com/websites/ai-website-builder

Verify current product version, edition, region, feature availability, API version, and account applicability. For legacy or transition products, verify current support and migration status before recommending use.

## Evidence Required

- Current GoDaddy product and help documentation for the subscribed plan and region.
- Account, plan, domain, DNS, site, content, commerce, booking, payment, marketing, permission, and analytics state.
- Content rights, privacy review, transaction tests, rollback, and approval evidence.

## Application Sequence

1. Define the decision, account scope, owner, date, and applicable source version.
2. Inventory evidence as `Verified`, `Provided`, `Assumed`, or `Needs verification`.
3. Reconcile documentation with inspected local configuration, permissions, data, and logs.
4. Draft the smallest reviewable GoDaddy website configuration and launch review brief with alternatives, risks, validation, rollback, and stop conditions.
5. Obtain explicit confirmation before register or transfer domains, change DNS, publish a site, sell products, take payments or bookings, send marketing, connect services, or represent availability or performance.

## Guardrails

- Do not invent domain ownership, DNS or SSL state, content rights, publication, inventory, price, booking availability, payment, consent, analytics result, or approval.
- Do not request credentials or expose secrets in the brief.
- Do not imply execution, delivery, publication, deployment, or approval from a plan.
