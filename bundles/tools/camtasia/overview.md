# Camtasia Overview

## Scope

- Screen, camera, microphone and system-audio capture; timeline editing; media, effects, annotations, captions, quizzes, and version-dependent interactive output.
- Source and license verification, privacy review, accessibility checks, export and LMS validation, learner-data controls, project packaging, versioning, approval, and handoff.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect Camtasia version license and operating environment, approved brief and audience, source captures media scripts brand assets fonts and rights, recording consent and personal-data boundaries, project timeline tracks effects captions audio descriptions quizzes and SCORM settings, accessibility review, export codec resolution platform and LMS requirements, learner-data handling, playback tests source package approvals and handoff authority.

## Boundary

Stop before record a person screen system or confidential data, import or publish protected media, alter source projects, create quizzes or SCORM packages, upload to an LMS or platform, collect learner data, or represent accessibility rights clearance learning results or approval without evidenced authority, validation, and explicit confirmation.
