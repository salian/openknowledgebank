# Klaviyo Overview

Source-aware guidance for Klaviyo profiles, events, segments, campaigns, flows, APIs, consent, measurement, and controlled activation.

## Evidence Contract

Relevant evidence includes account, plan, API revision, profiles, identifiers, consent and suppression status, lists, segments, events, metrics, catalogs, templates, campaigns, flows, channels, credentials, scopes, rate limits, integrations, attribution plan, tests, owners, and approvals. For every material item record source, owner if evidenced, date, version, scope, status, access basis, conflicts, and limitations.

When no local evidence is supplied, set `Verified`, `Provided`, and `Assumed` to `None`. Put exact missing artifacts under `Needs verification`. A general disclaimer is not a substitute for requesting evidence.

## Boundary

Analysis and drafting do not establish Plan and API availability, profile identity, consent and suppression state, segment membership, event accuracy, message approval, delivery, attribution, rate-limit behavior, cost, and authority. Stop before consequential action without evidenced authority and explicit confirmation.
