# Shortcut Overview

## Scope

- Stories, tasks, bugs, epics, milestones, iterations, objectives, roadmaps, workflows, states, labels, estimates, owners, teams, comments, files, documents, search, and reports.
- GitHub and other development integrations, Slack and automation, REST API, webhooks, imports, exports, permissions, audit evidence, workspace administration, evidence reconciliation, validation, and controlled delivery planning.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before create or alter stories, epics, iterations, objectives, workflows or estimates, send notifications, synchronize repositories, expose API tokens, run automations, change access, or represent status, effort, priority, dependency, delivery date, or completion without evidenced authority, validation, and explicit confirmation.
