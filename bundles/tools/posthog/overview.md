# PostHog Overview

## Scope

- Events, persons, groups, insights, funnels, paths, retention, cohorts, dashboards, session replay, feature flags, experiments, surveys, error tracking, and product analytics.
- SDKs, data capture, pipelines, CDP destinations, warehouse and SQL surfaces, APIs, webhooks, AI features, permissions, privacy controls, Cloud and self-hosted scope, billing, validation, and rollback.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current product identity and lifecycle, account or deployment, plan and region, users and roles, configuration, source data, permissions, integrations, logs, controls, validation, rollback, and approval evidence.

## Boundary

Stop before install capture, identify users, record sessions, change masking, flags or experiment allocation, send surveys, connect destinations, run queries, enable AI, expose keys, or represent behavior, significance, causality, security, or revenue without evidenced authority, validation, and explicit confirmation.
