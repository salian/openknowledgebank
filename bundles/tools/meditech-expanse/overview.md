# MEDITECH Expanse Overview

## Scope

- Edition- and module-dependent clinical, ambulatory, acute, patient-access, revenue-cycle, documentation, order, medication, reporting, interoperability, and mobile workflows.
- Environment discovery, patient-identity and role controls, interface and FHIR mapping, clinical-safety review, migration reconciliation, privacy and security validation, downtime planning, testing, rollback, approval, and release evidence.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect organization facility tenant version lifecycle and enabled modules, licensed care settings and approved workflows, patient provider encounter and master-data identity controls, users roles authentication and permissions, clinical documentation order medication decision-support scheduling and revenue-cycle configurations, interface FHIR vocabulary device and downstream mappings, test environment scripts clinical-safety and usability review, privacy security audit retention downtime business-continuity migration reconciliation rollback approvals and release authority.

## Boundary

Stop before access an environment or patient record, create alter migrate reconcile or disclose clinical or billing data, configure workflows orders medications alerts identities roles interfaces or FHIR access, release to production, or represent clinical correctness safety interoperability reimbursement compliance or approval without evidenced authority, validation, and explicit confirmation.
