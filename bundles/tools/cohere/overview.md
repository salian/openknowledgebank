# Cohere Overview

## Scope

- Chat and text generation, embeddings, reranking, retrieval, tool use, and enterprise language-model workflows.
- v2 API, models, deployments, authentication, safety controls, evaluation, observability, data governance, and integrations.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect current API and model versions, endpoint and deployment, region and data handling, credentials and scopes, prompts and system instructions, tools and retrieval sources, inputs and classifications, safety settings, parameters, outputs, citations, latency and cost, evaluations, monitoring, and approvals.

## Boundary

Stop before send sensitive data, call production models or tools, change deployments or safety settings, expose credentials, automate decisions, publish generated content, or represent model output as factual or approved without evidenced authority, validation, and explicit confirmation.
