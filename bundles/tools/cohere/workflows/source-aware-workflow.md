# Source-Aware Workflow

1. Record objective, account or project scope, date, constraints, and authorized owner.
2. Verify current official sources, edition, region, API or feature version, and lifecycle status.
3. Inspect current API and model versions, endpoint and deployment, region and data handling, credentials and scopes, prompts and system instructions, tools and retrieval sources, inputs and classifications, safety settings, parameters, outputs, citations, latency and cost, evaluations, monitoring, and approvals.
4. Separate `Verified`, `Provided`, `Assumed`, and `Needs verification`.
5. Reconcile conflicts among documentation, configuration, permissions, data, integrations, and logs.
6. Draft the Cohere configuration and use review brief with options, dependencies, privacy and security risks, validation, rollback, and stop conditions.
7. Require explicit confirmation before send sensitive data, call production models or tools, change deployments or safety settings, expose credentials, automate decisions, publish generated content, or represent model output as factual or approved.
