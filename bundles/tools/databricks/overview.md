# Databricks Overview

Use this bundle to prepare source-aware lakehouse data and analytics operations analysis and a reviewable databricks workspace and governance brief.

## Operating Principle

Start with the decision and evidence, not a presumed answer. Use current official or primary sources for general concepts and user-provided or authorized artifacts for local facts. Keep missing evidence visible, reconcile conflicts, and stop before consequential action without accountable approval.

## Scope

- General context: use the sources listed in the bundle metadata.
- Local conclusions: require current artifacts covering cloud, region, workspace, and runtime, catalog, schema, table, and volume scope, compute, warehouse, job, notebook, and query state, Unity Catalog grants and policies, lineage and data-quality evidence, and run history, usage, and cost definitions.
- Unknowns: do not infer data contents, lineage completeness, grant effectiveness, compute state, job outcome, and cost attribution.
- Action boundary: require confirmation before running jobs or SQL, creating or changing data or compute, changing grants or policies, handling secrets, or deleting resources.
