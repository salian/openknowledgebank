# Close CRM Overview

## Scope

- Leads, contacts, opportunities, activities, pipelines, reporting, calling, email, SMS, sequences, and bulk actions.
- REST API, OAuth, webhooks, event logs, MCP, integrations, permissions, and automation.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect organization and plan, API version, leads and contacts, lawful basis, consent and suppression, opportunities and stages, activities, mailboxes and phone numbers, sequences and bulk actions, users and permissions, OAuth and MCP scopes, webhooks, reports, attribution, and event logs.

## Boundary

Stop before import or update leads and contacts, change opportunities, enroll sequences, send email or SMS, place calls, run bulk actions, connect OAuth or MCP, or represent delivery or sales outcomes without evidenced authority, validation, and explicit confirmation.
