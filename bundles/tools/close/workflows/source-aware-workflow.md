# Source-Aware Workflow

1. Record objective, account or project scope, date, constraints, and authorized owner.
2. Verify current official sources, edition, region, API or feature version, and lifecycle status.
3. Inspect organization and plan, API version, leads and contacts, lawful basis, consent and suppression, opportunities and stages, activities, mailboxes and phone numbers, sequences and bulk actions, users and permissions, OAuth and MCP scopes, webhooks, reports, attribution, and event logs.
4. Separate `Verified`, `Provided`, `Assumed`, and `Needs verification`.
5. Reconcile conflicts among documentation, configuration, permissions, data, integrations, and logs.
6. Draft the Close CRM configuration and use review brief with options, dependencies, privacy and security risks, validation, rollback, and stop conditions.
7. Require explicit confirmation before import or update leads and contacts, change opportunities, enroll sequences, send email or SMS, place calls, run bulk actions, connect OAuth or MCP, or represent delivery or sales outcomes.
