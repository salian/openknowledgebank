# GitHub Copilot Source-Aware Triage

1. State the decision and direct answer possible now.
2. Record Verified, Provided, Assumed, and Needs verification separately.
3. Inspect the current source version and exact local evidence for Copilot plan and surface, IDE and extension version, repository and branch, selected context, organization and enterprise policies, model or agent mode, diffs, commands, tests, code-review evidence, data controls, approvals, and rollback.
4. Reconcile definitions, identifiers, dates, scope, permissions, processing, and ownership.
5. Record alternatives, stop conditions, and an independent cross-check.
6. Require explicit approval before actions that apply edits, run commands or tests, delegate coding-agent work, create commits or pull requests, change Copilot policies, send private code, expose credentials, or deploy changes.
7. End with a Source Note naming source URLs, user evidence, and missing sources.
