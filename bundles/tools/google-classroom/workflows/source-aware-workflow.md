# Source-Aware Workflow

1. Record objective, account or project scope, date, constraints, and authorized owner.
2. Verify current official sources, edition, region, API or feature version, and lifecycle status.
3. Inspect tenant and edition, classes, rosters and roles, assignments and rubrics, submissions, grades and feedback, guardian settings, originality reports, integrations, permissions, logs, policies, validation, and approvals.
4. Separate `Verified`, `Provided`, `Assumed`, and `Needs verification`.
5. Reconcile conflicts among documentation, configuration, permissions, data, integrations, and logs.
6. Draft the Google Classroom configuration and learning workflow review brief with options, dependencies, privacy and security risks, validation, rollback, and stop conditions.
7. Require explicit confirmation before create classes, enroll or remove users, publish assignments, return submissions, change grades, contact guardians, run originality checks, connect an SIS, export student data, or represent learning outcomes.
