# Gitea Overview

## Scope

- Git hosting, repositories, issues, pull requests, packages, Actions, organizations, webhooks, and APIs.
- Self-hosting, upgrades, authentication, permissions, secrets, runners, backups, audit evidence, and validation.

## Evidence Contract

Product documentation can establish documented capabilities. It cannot establish the local edition, configuration, data, access, integration state, execution result, or approval. Inspect deployment and version, repositories, branches, organizations, users and permissions, authentication, secrets, runners, workflows, packages, webhooks, logs, backups, tests, rollback, and approvals.

## Boundary

Stop before create or delete repositories, merge code, change access, run workflows, expose secrets, publish packages, upgrade or migrate a server, restore backups, or represent security or deployment state without evidenced authority, validation, and explicit confirmation.
