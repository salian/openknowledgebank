# Source Checks

- Scrum terminology, Product Goal, Product Backlog, ordering, refinement, and sizing: [Scrum Guide 2020](https://scrumguides.org/scrum-guide.html).
- Current official guide release information: [Scrum Guides download page](https://scrumguides.org/download.html).
- Backlog transparency, currency, and ordering: [Scrum.org Introduction to the Product Backlog](https://www.scrum.org/resources/introduction-product-backlog).
- User-story format as a complementary practice: [Scrum.org User Story Format](https://www.scrum.org/resources/blog/user-story-format).
- Optional ordering factors and techniques: [Scrum.org Product Backlog Ordering](https://www.scrum.org/resources/blog/product-backlog-ordering-beyond-moscow).

## Inspection Rule

For local work, inspect the current product brief, research, analytics definition, architecture or constraint record, team policy, and source-of-record backlog before asserting exact facts. Name the artifact, version or date, scope, and reviewer evidence used.
