# Product Backlog / User Stories

This deliverable is the reviewable backlog item described in [Product Backlog Item / User Story](deliverables/product-backlog-item.md). It should connect supplied product evidence to a Product Goal or explicitly identify the missing goal, define observable acceptance criteria, explain ordering, and preserve unresolved facts as `Needs verification`.

## Source Note

Primary source: [Scrum Guide 2020](https://scrumguides.org/scrum-guide.html). User-story syntax and optional ordering practices are supporting techniques, not universal Scrum requirements.
