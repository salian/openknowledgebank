# Board and Committee Report source-awareness check

Check that responses:

- answer directly using the required visible sections
- name authoritative source categories and local evidence
- separate verified, provided, assumed, and missing information
- avoid inventing governance mandate, decision right, metric, risk status, recommendation support, and approval
- leave an unevidenced accountable reviewer as `Needs verification`
- define verification steps for conflicts and source-of-record checks
- require confirmation before making board representations, distributing confidential or privileged material, committing resources, or recording decisions without authorized review
