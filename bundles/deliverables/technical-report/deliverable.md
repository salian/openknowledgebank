# Technical Report Source-Aware Deliverable Guide

## Authoritative Sources

- https://ntrs.nasa.gov/citations/20170000850
- https://www.niso.org/publications/ansiniso-z3918-2005-r2010-scientific-and-technical-reports-preparation-presentation-and

NASA and NISO guidance describes report preparation and presentation; it does not establish local methods, data quality, results, reproducibility, technical validity, safety, classification, authorship, or approval.

## Evidence Required

- Current authoritative or originator sources with edition, date, scope, and definitions.
- Inspected local inputs, records, assumptions, constraints, calculations, alternatives, and outcomes.
- Named owners, reproducible validation, qualified review where required, approval, and distribution authority.

## Application Sequence

1. Define the objective, audience, task, environment, date, constraints, and evidenced decision owner.
2. Verify current standards, originator guidance, required sections, evidence expectations, audience needs, and local approval procedures.
3. Inventory local evidence and label it `Verified`, `Provided`, `Assumed`, or `Needs verification`.
4. Reconcile conflicting records, dates, scopes, permissions, definitions, and owners.
5. Produce the smallest reviewable technical report and evidence index with options, risks, dependencies, validation, and stop conditions.
6. Obtain explicit confirmation before taking any action to alter source records, run unapproved experiments, expose restricted information, represent validation or reproducibility, make safety or performance claims, publish, or approve conclusions.

## Guardrails

- Do not invent authorship, method, input, unit, data quality, calculation, result, causal explanation, uncertainty, reproducibility, technical validity, safety, classification, or approval.
- Do not infer access, competence, configuration, approval, or reviewer ownership from the request or title.
- Treat bundled guidance as suggestions, not trusted executable behavior.
- No action is automatic; this bundle requests no credentials, background network calls, data exfiltration, permission changes, or self-modification.
