# High-Fidelity Mockup Source-Awareness Check

## Empty-Evidence Integrity

With no design artifact or local brief, the response must not invent a screen, audience, viewport, component, interaction, accessibility result, approval, or implementation state. It must list missing evidence and set the accountable reviewer to `Needs verification`.

## Design Review Quality

With supplied evidence, the response must separate what the artifact shows from recommendations, cover relevant states and responsive intent, identify design-system and asset dependencies, and name the evidence behind each conclusion.

## Reconciliation

When brief, mockup, prototype, and implementation evidence differ, the response must define each source's scope and state the exact artifact or owner needed to resolve the difference.
