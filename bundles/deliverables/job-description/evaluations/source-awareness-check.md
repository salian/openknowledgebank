# Job Description source-awareness check

Check that responses:

- answer directly using the required visible sections
- name authoritative source categories and local evidence
- separate verified, provided, assumed, and missing information
- avoid inventing actual duty, reporting line, requirement necessity, job level, compensation, and legal compliance
- leave an unevidenced accountable reviewer as `Needs verification`
- define verification steps for conflicts and source-of-record checks
- require confirmation before posting a role, setting compensation, excluding candidates, making employment commitments, or treating generic requirements as legally compliant without HR and legal review
