# Incident Postmortem Report source-awareness check

Check that responses:

- answer directly using the required visible sections
- name authoritative source categories and local evidence
- separate verified, provided, assumed, and missing information
- avoid inventing timeline event, impact, root or contributing cause, individual intent, remediation effectiveness, and closure status
- leave an unevidenced accountable reviewer as `Needs verification`
- define verification steps for conflicts and source-of-record checks
- require confirmation before assigning blame, making legal, security, employment, or public claims, closing actions, or publishing the report without accountable review
