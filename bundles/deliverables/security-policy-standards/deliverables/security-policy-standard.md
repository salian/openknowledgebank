# Security Policy or Standard

## Decision and Status

State the decision supported and whether the artifact is draft, review copy, approved, or superseded. Do not claim approval without evidence.

## Source Note

Name authoritative source categories inspected, URLs or identifiers, editions and access dates, local evidence used, and missing sources still needed.

## Evidence Status

| Item | Verified | Provided | Assumed | Needs verification |
| --- | --- | --- | --- | --- |
| Scope and affected systems/data | None unless inspected | None unless supplied | None | Exact missing boundaries |
| Applicable obligations | None unless inspected | None unless supplied | None | Jurisdictions, contracts, regulators |
| Owner, approver, exception authority | None unless evidenced | None unless supplied | None | Governance record |
| Existing controls and effectiveness | None unless evidenced | None unless supplied | None | Approved evidence |

## Document Control

Title, identifier, version, status, owner, approver, effective date, review date, change history, and distribution are populated only from supplied governance evidence.

## Purpose, Scope, Definitions, and Requirements

State the objective, included and excluded people/processes/systems/data, and local meanings of policy, standard, procedure, guideline, control, exception, and evidence. For each requirement, state rationale, applicability, implementation evidence, responsible function if verified, and source mapping. Label illustrative wording.

## Exceptions, Enforcement, Review, and Change

Record rationale, risk, compensating measures, accountable owner, approval evidence, expiry, review date, enforcement path, source refresh method, change impact, and supersession record. Do not create a generic approver or accept risk on the organization’s behalf.

## Cautious Conclusion

State what is ready for review, what is unsupported, and the exact next evidence or qualified review needed before approval, enforcement, publication, audit reliance, or certification claims.
