# OKR / Goal-Setting Framework

This bundle helps an agent produce a review-ready organizational or team goals framework. It is a deliverable companion to the broader `frameworks/okrs` bundle.

## Required Answer Contract

Every substantive output must include:

1. **Direct answer** - state what the framework does and what decision is requested.
2. **Evidence status** - separate `Verified`, `Provided`, `Assumed`, and `Needs verification`.
3. **Framework** - show objectives, key results, initiatives, dependencies, and review logic.
4. **Decision and confirmation boundary** - name the accountable reviewer or say `Needs verification`.
5. **Source note** - name public framework sources, local evidence, and limitations.
