# Source Checks

- Use [What Matters' OKR definition](https://www.whatmatters.com/faqs/okr-meaning-definition-example) for general terms.
- Use [What Matters' OKR writing guide](https://www.whatmatters.com/faqs/okr-examples-and-how-to-write-them) for objective/KR writing.
- Use [Atlassian's OKR guide](https://www.atlassian.com/agile/agile-at-scale/okr) and [OKR play](https://www.atlassian.com/team-playbook/plays/okrs) for practical review guidance.
- Use local strategy, metric definitions, reports, policies, and authorized system evidence for targets, baselines, ownership, dates, cadence, scoring, and commitments.
- Record source date/version and reconcile scope, definitions, time window, calculation, and source-of-record.
