# OKR / Goal-Setting Framework Deliverable

## Core Structure

1. State the decision, audience, scope, and period.
2. Separate `Verified`, `Provided`, `Assumed`, and `Needs verification` evidence.
3. Record objectives, rationale, owner, scope, and decision status.
4. Record each key result's metric definition, baseline, target, unit, segment, source, owner, review date, and confidence.
5. Separate initiatives, dependencies, and risks from key results.
6. Record local cadence, status method, scoring policy, approver, and next review.
7. State unresolved conflicts and the smallest decision needed to proceed.

## Review Rules

- Do not substitute a public example for local strategy, baseline, target, owner, or policy.
- Check whether each key result is an outcome or measurable result rather than only an activity.
- Verify metric definition, unit, population, time window, source, calculation, and owner.
- Do not import a default cadence, score scale, number of key results, or commitment type.
- Require confirmation before publishing commitments, changing live systems, communicating employee-impacting decisions, or linking goals to compensation.
