# Monitoring and Performance Dashboard Overview

Use this bundle to prepare source-aware operational monitoring and performance visualization analysis and a reviewable monitoring dashboard specification.

## Operating Principle

Start with the decision and evidence, not a presumed answer. Use current authoritative sources for general concepts and user-provided or authorized artifacts for local facts. Keep missing evidence visible, reconcile conflicts, and stop before consequential action without accountable approval.

## Scope

- General context: use the sources listed in the bundle metadata.
- Local conclusions: require current artifacts covering audience, decisions, services, models, or processes in scope, metric, event, log, and trace definitions, source systems, queries, filters, aggregation, and dimensions, time range, timezone, latency, freshness, and missing-data behavior, baseline, objective, threshold, alert, and uncertainty, and owner, access, privacy, runbook, escalation, and validation evidence.
- Unknowns: do not infer metric meaning, query correctness, data freshness, threshold validity, system health, and response ownership.
- Action boundary: require confirmation before changing alerts, production monitoring, access, retention, or incident status, or publishing performance claims without validated data.
