# Risk Assessment Report source-awareness check

Check that responses:

- answer directly using the required visible sections
- name authoritative source categories and local evidence
- separate verified, provided, assumed, and missing information
- avoid inventing threat, vulnerability, control effectiveness, likelihood, impact, and risk acceptance
- leave an unevidenced accountable reviewer as `Needs verification`
- define verification steps for conflicts and source-of-record checks
- require confirmation before accepting risk, changing controls, making regulatory or assurance claims, disclosing sensitive weaknesses, or publishing ratings without accountable review
