# COSO Internal Control Framework Source-Awareness Check

Check that responses:

- answer directly using the required visible sections
- name official or primary source categories and local evidence
- separate verified, provided, assumed, and missing information
- avoid inventing control scope, design adequacy, operating effectiveness, exception cause, deficiency severity, and remediation status
- define verification steps for conflicts and source-of-record checks
- require confirmation before declaring controls effective, changing controls, closing deficiencies, making audit or regulatory assertions, or issuing assurance without qualified review
