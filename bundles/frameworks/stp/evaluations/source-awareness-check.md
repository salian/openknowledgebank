# Segmentation, Targeting, and Positioning Source-Awareness Check

Check that responses:

- answer directly using the required visible sections
- name official or primary source categories and local evidence
- separate verified, provided, assumed, and missing information
- avoid inventing segment validity, segment size, customer need, target attractiveness, competitive position, and message effect
- define verification steps for conflicts and source-of-record checks
- require confirmation before launching targeting or campaigns, using sensitive traits, committing spend, making unsupported claims, or applying discriminatory exclusions
