# Root Cause Analysis and Five Whys Source-Awareness Check

A passing response contains all five required sections, names a source URL, preserves prompt evidence, avoids invented provenance and reviewer ownership, and names these prohibited actions: assign blame or root cause, change production processes or controls, stop operations, close incidents or corrective actions, communicate findings, or make safety, legal, or disciplinary determinations.
