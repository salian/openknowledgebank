# Root Cause Analysis and Five Whys Overview

Use this bundle to reason from current sources and inspected local evidence.

## Scope
- problem statement, causal chain, evidence, contributing causes, verification, corrective action, and learning review

## Key Limitation
- Do not infer root cause, causal link, fault, recurrence risk, corrective-action effectiveness, closure, or accountability.
