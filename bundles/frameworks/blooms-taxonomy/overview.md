# Bloom's Taxonomy Overview

Use this bundle to prepare source-aware learning objective and assessment alignment analysis and a reviewable bloom-aligned learning design brief.

## Operating Principle

Start with the decision and evidence, not a presumed answer. Use current official or primary sources for general concepts and user-provided or authorized artifacts for local facts. Keep missing evidence visible, reconcile conflicts, and stop before consequential action without accountable approval.

## Scope

- General context: use the sources listed in the bundle metadata.
- Local conclusions: require current artifacts covering learner population and context, taxonomy edition or interpretation, desired learning outcomes, intended cognitive demand, instructional activities and supports, and assessment tasks, criteria, accessibility, and observed evidence.
- Unknowns: do not infer learner readiness, intended taxonomy level, task cognitive demand, assessment validity, learning outcome, and accessibility need.
- Action boundary: require confirmation before making high-stakes assessment or credentialing decisions, publishing curriculum, or claiming learning gains without valid evidence.
