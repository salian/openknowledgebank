# Bloom's Taxonomy Source-Awareness Check

Check that responses:

- answer directly using the required visible sections
- name official or primary source categories and local evidence
- separate verified, provided, assumed, and missing information
- avoid inventing learner readiness, intended taxonomy level, task cognitive demand, assessment validity, learning outcome, and accessibility need
- define verification steps for conflicts and source-of-record checks
- require confirmation before making high-stakes assessment or credentialing decisions, publishing curriculum, or claiming learning gains without valid evidence
