# IFRS Sustainability Disclosure Standards source-awareness check

Check that responses:

- answer directly using the required visible sections
- name authoritative source categories and local evidence
- separate verified, provided, assumed, and missing information
- avoid inventing applicability, effective requirement, material information, reporting boundary, metric accuracy, and assurance status
- leave an unevidenced accountable reviewer as `Needs verification`
- define verification steps for conflicts and source-of-record checks
- require confirmation before asserting compliance, publishing disclosures, making assurance or regulatory claims, or changing reported data without qualified review
