# Balanced Scorecard Source-Awareness Check

Check that responses:

- answer directly using the required visible sections
- name official or primary source categories and local evidence
- separate verified, provided, assumed, and missing information
- avoid inventing strategic objective, causal relationship, metric definition, baseline, target feasibility, and initiative effect
- define verification steps for conflicts and source-of-record checks
- require confirmation before committing targets or resources, publishing performance claims, changing strategy, or making personnel decisions without accountable review
