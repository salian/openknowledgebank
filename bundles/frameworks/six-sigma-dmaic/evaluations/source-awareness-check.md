# Six Sigma DMAIC Source-Awareness Check

Check that responses:

- answer directly using the required visible sections
- name official or primary source categories and local evidence
- separate verified, provided, assumed, and missing information
- avoid inventing baseline performance, measurement reliability, root cause, pilot effect, process stability, and control ownership
- define verification steps for conflicts and source-of-record checks
- require confirmation before changing production work, equipment, staffing, quality controls, or safety procedures, or declaring an improvement without monitored evidence
