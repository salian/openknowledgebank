# GRI Standards Source-Awareness Check

Check that responses:

- answer directly using the required visible sections
- name official or primary source categories and local evidence
- separate verified, provided, assumed, and missing information
- avoid inventing applicable standard, reporting boundary, material topic, disclosure completeness, data quality, and assurance status
- define verification steps for conflicts and source-of-record checks
- require confirmation before publishing sustainability claims, asserting compliance or assurance, omitting required information, or changing reported data without accountable review
