# MoSCoW Prioritization source-awareness check

Check that responses:

- answer directly using the required visible sections
- name authoritative source categories and local evidence
- separate verified, provided, assumed, and missing information
- avoid inventing requirement necessity, effort, dependency, deadline feasibility, priority agreement, and tradeoff effect
- leave an unevidenced accountable reviewer as `Needs verification`
- define verification steps for conflicts and source-of-record checks
- require confirmation before committing scope, deadlines, resources, contractual obligations, or dropping safety, compliance, or critical requirements without accountable approval
