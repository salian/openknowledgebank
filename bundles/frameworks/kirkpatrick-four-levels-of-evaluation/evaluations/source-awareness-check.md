# Kirkpatrick Model Source-Awareness Check

Check that responses:

- answer directly using the required visible sections
- name official or primary source categories and local evidence
- separate verified, provided, assumed, and missing information
- avoid inventing model version, target result, behavior change, learning gain, participant reaction, and attribution
- define verification steps for conflicts and source-of-record checks
- require confirmation before claiming causality or return on investment, changing programs, monitoring employees, or making personnel decisions without appropriate evidence and review
