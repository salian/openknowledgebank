# Kirkpatrick Model Overview

Use this bundle to prepare source-aware learning-program evaluation analysis and a reviewable kirkpatrick evaluation design brief.

## Operating Principle

Start with the decision and evidence, not a presumed answer. Use current official or primary sources for general concepts and user-provided or authorized artifacts for local facts. Keep missing evidence visible, reconcile conflicts, and stop before consequential action without accountable approval.

## Scope

- General context: use the sources listed in the bundle metadata.
- Local conclusions: require current artifacts covering current model version and official definitions, target organizational results, critical behaviors and performance environment, learning outcomes and assessment evidence, reaction and engagement evidence, and baseline, timing, comparison, confounders, and data quality.
- Unknowns: do not infer model version, target result, behavior change, learning gain, participant reaction, and attribution.
- Action boundary: require confirmation before claiming causality or return on investment, changing programs, monitoring employees, or making personnel decisions without appropriate evidence and review.
