# Medicaid Provider Enrollment Screening Review Workflow

## 1. Scope

Identify state/program, FFS/managed care, provider type, individual/entity, role, locations, ownership/control and managing persons, event, dates, requested decision, and accountable reviewer. Mark gaps `Needs verification`.

## 2. Resolve Sources

Capture current and event-date Subpart E text, supporting Subpart B disclosure rules where applicable, MPEC guidance, and current state law/plan/manual/application/agreement/bulletin/managed-care/appeal sources. Separate federal rule, CMS guidance, and state implementation.

## 3. Classify Event and Risk

Determine whether the event is initial enrollment, reenrollment/revalidation, reactivation, change, ordering/referring enrollment, reliance review, or adverse-action review. Record the supported risk category and adjustment facts; do not infer them.

## 4. Build Activity Matrix

Map license, identity, ownership/control, database, site-visit, criminal-background/fingerprint, fee, moratorium, disclosure, and state-added activities to exact sources, affected persons, triggers, timing, and evidence.

## 5. Review Reliance

Where Medicare/another-state screening is proposed, verify identity match, current status, screening date/scope, completed activities, and remaining state requirements. Preserve the state agency's independent recurring database duties.

## 6. Test Evidence

Use authorized, minimum-necessary evidence. Record source/date, reviewer, result status, conflicts and gaps. Do not execute checks or convert a possible match/missing record into an exclusion or adverse decision.

## 7. Reconcile Decision

State verified federal baseline, verified state implementation, evidence, assumptions, needs-verification items, narrow supported answer, accountable owner, and unauthorized actions. If state/provider context or current authority is missing, make no eligibility/compliance conclusion.

## 8. Monitor

Track revalidation/change triggers, licenses, ownership/control, risk changes, databases, exclusions/terminations, fees, moratoria, state rules, managed-care arrangements, and notices. Revalidate on source or provider change.
